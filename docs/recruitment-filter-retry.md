# 영입 필터 상태 확인 및 재시도

이슈 18의 v1.5.16 보고서에서는 불 속성과 기사 필터가 선택되어 있지만 `속성 선택 완료 확인`에서 종료했다. 해당 캡처에서 불 속성 선택 마커와 필터 메뉴는 인식됐고 영웅 목록의 기사 아이콘은 인식되지 않았다. 필터가 목록을 가리므로 라스의 미노출이나 부재를 뜻하지 않는다.

클래스 아이콘은 필터를 열기 전 목록 및 필터 버튼 확인 단계에서 검증한다. 이후 속성 확인은 필터 메뉴와 선택·미선택 버튼 상태에만 의존한다. 버튼 전후 상태가 미선택에서 선택으로 바뀌고 중심이 같은 위치에 유지되는지 확인한다. 전체 화면 변화나 일시적인 눌림 효과만으로 성공 처리하지 않는다.

필터/속성 처리에는 최대 3회 재확인 루프를 적용한다. 입력 후 1초 동안 사용자 중단을 받으며 기다리고 안정된 상태를 확인한다. 필터가 여전히 닫혔으면 클래스 아이콘과 버튼을 다시 확인해 열고, 열려 있다면 열기 입력을 생략한다. 속성이 미선택이면 입력 직전 재확인 후 클릭하고, 이미 선택된 경우 클릭을 건너뛴다. 속성 처리 중 필터가 닫히면 다음 시도에서 목록의 클래스부터 다시 확인한다. 미확인 화면에는 입력하지 않고 기존 인식 대기를 수행하며, 3회 실패하면 중지한다.

이미 선택된 다른 속성을 함께 발견했을 때의 초기화 안내, 대상 영웅 검색과 금색 테두리 검증, 비용 초과 및 대체 영입 처리는 유지한다. 기사 단독과 파티 영입은 같은 필터 처리 함수를 사용한다.

이슈 캡처는 테스트용 원본으로만 보관하고 배포 이미지 목록에는 포함하지 않는다. 실제 게임에서의 연속 실행과 배포본 간 자동 업데이트는 별도 확인이 필요하다.
