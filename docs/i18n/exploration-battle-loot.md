# 전투 결과 전리품 인식 및 미수령 경고 복구

## 확인한 문제

2026-10-24 22:35 및 22:37 로그에서 승리 후 전리품을 열지 않고 계속 탐사를
눌렀다. 22:38:40 오류 보고 화면에는 영문 미수령 보상 경고가 남아 있었다.
기존 전리품 선택·영웅 영입·전투 랭크업 버튼은 한글 글자 조각을 사용했다.

## 변경

- 전투 결과의 전리품 상자·직업·랭크업 아이콘과 같은 카드의 활성 파란 버튼을
  연결한다. 버튼 글자는 제외하며, 카드 테두리도 함께 확인한다.
- 카드가 2개 또는 3개여도 각 버튼 위에서 아이콘을 찾는다. 수령한 비활성
  카드는 대상으로 삼지 않는다. 종류를 알 수 없는 활성 보상은 진행을 중지한다.
- 전리품 수령을 우선하고, 수령 후 결과 화면을 다시 검사한다. 계속 탐사
  클릭 직전에도 전리품·랭크업·미확인 보상이 나타나면 입력을 보류한다.
- 두 버튼과 어두워진 VICTORY 배경으로 확인한 전투 경고는 취소한 뒤 남은
  보상을 다시 검사한다. 추가 영웅을 의도적으로 건너뛴 직후의 확인은 기존의
  제한된 처리 경로를 유지한다.
- 기존 실패 진단에 전투 보상 아이콘·카드·버튼과 경고 취소 인식을 추가한다.
  상시 이미지 수집이나 새로운 캡처 반복 작업은 추가하지 않는다.

## 검증 범위

신규 영문 2카드 결과 화면, 실제 영문 경고 화면, 기존 한국어 3카드·랭크업·
수령 완료 화면을 재생한다. 글자 변경, 아이콘/카드/버튼 누락, 미확인 보상,
클릭 직전 전리품 재등장과 수령 후 재검사를 검사한다. 실제 게임 입력은
전송하지 않는다.

후속 오류 보고에서 영문 전리품 **미선택 목록 화면**을 확보했다.
[선택 목록 인식 보완](exploration-loot-selection.md)을 참조한다.
영문 선택 완료·수령 확정 화면의 실제 게임 검증은 아직 필요하다.

검증 결과: 관련 5개 테스트 모듈의 67개 테스트 통과. 새 런타임 템플릿이
릴리즈 이미지 목록에 포함되는 것도 확인했다.

추가로 전리품과 영웅 영입이 함께 있는 기존 3카드 캡처에서 전리품 열기 →
수령 후 결과 재검사 → 남은 영웅 영입 건너뛰기 → 지도 복귀 순서를 재생했다.
수령 완료는 전리품 버튼을 제거한 합성 화면으로 모델링하며, 실제 영입 경고
확인 동작은 기존 별도 테스트가 검증한다. 관련 2개 모듈 18개 테스트 통과.

## 2026-10-25 배경 변화 보완

08:00:18 오류 보고에서는 전리품 아이콘과 활성 버튼은 인식했지만 카드
테두리 비교가 실패해 미확인 보상으로 중지됐다. 반투명한 긴 테두리 주변에
비치는 전투 배경의 차이가 비교에 포함돼 있었다.

카드 크기 252×426 안에서 좌우 아래 꺾임 두 부분(각 16×35, 상대 y=275)만
비교하도록 마스크를 좁혔다. 임계값은 0.90을 유지한다. 전투 카드 검사에서
이전의 넓은 영입 카드 테두리 템플릿을 대체 경로로 사용하지 않는다.
아이콘·같은 카드의 활성 버튼 검증과 미확인 보상 중지는 유지한다.

최신 실제 오류 화면을 회귀 자료에 추가했다. 제외 영역 전체를 임의 픽셀로
바꾸되 별도로 검사하는 아이콘·버튼을 유지하는 검사와, 좌우 장식 중 하나를
지웠을 때 보상으로 판정하지 않는 검사도 추가했다. 실제 게임 입력은 전송하지 않는다.

이번 보완 검증: 전투 보상·영입 건너뛰기·이벤트 흐름의 3개 모듈 38개 테스트 통과.

## 전체 직업 영입권

2026-10-25 08:17:43 보스 승리 화면에서는 전리품 인식은 성공했으나,
All-Class 영입권이 기존 6개 직업 아이콘에 해당하지 않아 미확인 보상으로
중지됐다. 실제 화면의 `All` 배지(64×64)를 영입권 아이콘 참조에 추가했다.
설명이나 버튼 문구는 읽지 않으며 동일 카드 테두리와 활성 버튼을 요구한다.
미확인 보상 중지와 전리품 우선 수령 정책은 그대로 유지한다.

실제 영문 전투 결과 화면의 동시 보상을 인식하고 전리품 수령 → 결과 재검사
→ 영입 건너뛰기 순서로 처리하는지 재생한다. 수령 완료는 버튼 제거로
모델링하고 전리품 선택·영입 경고 처리는 기존 별도 검사 범위를 따른다.
독립 영입 보상창의 All 배지는 합성 배치로 검사하며 실제 해당 화면을
제공받은 것은 아니다. 아이콘·테두리·활성 버튼 누락도 검사한다.

이번 보완 검증: 관련 테스트 35개 통과(34개 회귀 검사와 독립 보상창 합성 검사 1개).
새 배지 참조의 릴리즈 이미지 포함 여부도 확인했다.
