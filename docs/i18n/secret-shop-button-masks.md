# 비밀상점 버튼 문자 제외 마스크

- 작업일: 2026-10-23
- 범위: 비밀상점 구입·구입 비활성·구매·확인·갱신 버튼의 기본/백업 이미지 10개
- 상태: 마스크 구현 및 자동 검사 완료. 실제 영어 게임 화면·실행 검증 전

## 이미지와 미리보기

- [원본/마스크 비교 미리보기](secret-shop-button-masks.html)
- 투명 PNG: `images/buttons/masked/`
- 제외 영역 정의: `images/buttons/template_masks.json`
- 재생성: 저장소 루트에서 `python tools/build_shop_button_masks.py`

원본 PNG의 픽셀과 크기는 보존한다. 제외 영역 정의에서 `[x, y, width, height]`로 지정한 사각형을 투명하게 만든 템플릿을 메모리에서 사용한다. 생성된 `masked/` PNG는 이 정의로부터 만든 검토용 산출물이며, 별도 마스크 JSON 없이도 같은 매칭에 사용할 수 있다. 투명 픽셀의 RGB도 검토용 PNG에서는 지운다.

| 버튼 | 원본 크기 | 제외 영역 | 비교에 남는 영역 |
|---|---|---|---|
| 구매 | 63×39 | `[3, 6, 57, 29]` | 바깥 여백·색상, 약 32.7% |
| 확인 | 102×41 | `[6, 5, 90, 29]` | 외곽·하단 색상, 약 37.6% |
| 구입 / 비활성 구입 | 183×53 | `[90, 5, 89, 43]` | `1/1` 또는 `0/1`, 좌측·외곽·색상, 약 60.5% |
| 갱신 | 104×46 | `[3, 6, 98, 34]` | 바깥 여백·색상, 약 30.4% |

구입 버튼은 수량 영역이 왼쪽에 있으므로 문자 영역인 오른쪽을 제외한다. 나머지는 중앙을 넓게 제외한다. 기본과 백업에 같은 규칙을 적용한다. 템플릿의 전체 사각형을 유지하므로 감지 결과와 클릭 중심의 좌표 체계는 유지된다.

## 인식 구현

`ImageMatcher`가 템플릿 옆의 `template_masks.json`을 읽어 파일명별 마스크를 적용한다. 정의가 없는 일반 이미지는 기존 매칭 방식을 유지한다. 알파 채널이 있는 PNG도 투명 영역을 제외해 읽는다. 알파값이 0인 픽셀을 제외하고, 0보다 큰 픽셀은 동일한 가중치로 비교한다.

일반 마스크 매칭은 제외 영역 밖의 모양 상관도와 절대 색상 차이를 함께 사용한다. 최종 점수는 두 조건 중 낮은 값이다. 구매·확인·갱신 버튼의 기존 임계값은 낮추지 않는다.

구입·비활성 구입 버튼은 후속 [구매 전후 수량 비교](secret-shop-purchase-transition.md)에서 색상 조건을 제거했다. 실제 구입 가능·완료 판정은 흑백 모양 탐색과 같은 상품의 `1/1 → 0/1` 변화 확인을 사용한다. 일반 매칭 점수만으로 구입 상태를 결정하지 않는다.

- 단일 탐색, 전체 탐색, 최대 유사도, 특정 위치 유사도에서 같은 방식을 사용한다.
- GUI 이미지 테스트에서도 같은 템플릿을 사용한다. 구입 버튼은 흑백 모양 점수를 표시하며 실제 판정에는 같은 상품·수량 확인이 추가됨을 안내한다. 진단 폴더에는 원본과 `masked_template.png`를 함께 저장한다.
- 마스크 정의가 변경되면 템플릿 캐시를 갱신한다. 크기가 틀리거나 범위를 벗어나거나 전체가 투명한 정의는 오류로 처리하고 매칭을 중단한다.
- 마스크 정의 JSON을 배포 자산에 포함한다. 검토용 `masked/` PNG와 HTML, 문서는 배포 이미지 목록에 추가하지 않는다.

## 검증과 남은 확인

자동 검사에서는 각 버튼의 제외 영역 픽셀을 임의의 다른 픽셀로 바꾸어도 원래 위치·크기로 탐지되는지 확인했다. 일반 색상 포함 매칭에서 활성·비활성 구입 버튼의 교차 점수는 약 0.728이었다. 이 수치는 저장된 템플릿 간 비교 결과이며 실기 정확도를 의미하지 않는다. 후속 수량 비교에서는 이 점수로 구입 상태를 판단하지 않는다.

또한 빈 검정·회색·흰 화면의 오인식, 유효하지 않은 매칭 점수, 잘못된 마스크, 캐시 갱신, 투명 PNG 재사용, GUI 진단 템플릿 저장과 배포 목록을 검사했다. 관련 기존 검사와 매크로·릴리즈 패키지 검사를 포함해 50개 검사가 통과했다.

다음은 아직 확인하지 않았다.

- 실제 한국어·영어 비밀상점의 짝 화면에서 문구 폭, 버튼 폭 및 상태별 배치가 같은지 여부.
- 문자 제외 영역 밖에 긴 영어 문구가 남는지 여부.
- 유사한 색·외곽을 가진 다른 버튼이나 팝업에서의 오인식 여부.
- ADB/STOVE 실기에서 구매·갱신·자연 갱신·구매 완료 확인의 전체 흐름.

특히 구매·갱신 원본은 완전한 버튼 테두리 대신 버튼 내부를 작게 잘라 둔 이미지다. 문자 제외 후 남는 고유 특징이 적으므로 이 방식만으로 영어 지원 완료를 선언할 수 없다. 실화면 비교에서 구분력이 부족하면 버튼 테두리가 더 포함된 원본으로 다시 수집하거나 검색 영역·화면 상태 제약 또는 언어별 이미지를 추가해야 한다. 클릭 순서는 유지하며 구입 전후 상품 행은 아이콘으로 재확인한다.
