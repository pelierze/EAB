# 전투 보상은 작은 아이콘과 둥근 버튼으로 연결

2026-10-26 23:17:04 보고는 전리품 아이콘과 활성 버튼이 검출됐지만
반투명 카드의 테두리가 검출되지 않아 미확인 보상으로 중지한 사례다.

카드 테두리 검사를 제거하고 보물상자/랭크업/직업/전직업 아이콘과 아래의
긴 둥근 활성 버튼을 짝짓는다. 보물상자 참조는 73×60으로 좁혔으며 버튼은
212×55 영역에서 중앙 글자를 마스킹한다. 카드 제목·설명과 테두리를 사용하던
불필요한 기존 마커도 제거했다. 영웅 영입권이 없어도 전리품 아이콘과 버튼
한 쌍이면 유효하다. 영입권 또는 랭크업 단독 보상도 같은 방식으로 처리한다.

승리 화면 안에서 아이콘이 버튼의 위쪽 같은 열에 있고, 보상 종류와 짝이
유일할 때만 버튼을 반환한다. 중복되거나 모호한 보상 종류를 덮어쓰지 않는다.
알 수 없는 활성 버튼은 기존 미확인 보상 검사로 계속 탐사를 막는다.
전리품을 먼저 수령하고 다시 관측해 남은 영입 보상 등을 처리하는 흐름은
유지한다. 클릭 직전 재검사와 금지 항목 검사도 유지한다.

검증에는 최신 실제 캡처, 기존 한글/영문 보상, 단독 전리품/영입권/랭크업,
각 직업 아이콘, 카드/배경/문구 제거, 필수 아이콘/버튼 누락, 모호한 중복,
전리품 먼저 수령 후 영입 보상 처리와 패키지 이미지 참조 검사를 포함한다.
합성 캡처와 모의 입력을 사용하며 실제 게임 입력은 보내지 않는다.

검증 결과: 전투 전리품, 영입 보상 건너뛰기, 랭크업 결과 및 이미지 패키지
검사를 합쳐 58개 통과. 이미지 감사표 갱신, `compileall`, `git diff --check` 완료.
