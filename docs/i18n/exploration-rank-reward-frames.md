# 이벤트 랭크업 보상 버튼의 언어 독립화

2026-10-25 17:40:56 보고에서는 17:39:14 이벤트 선택 후 랭크업 보상
카드가 나타났지만 `이벤트 선택 결과 확인`에서 세 차례 대기 후 중지했다.
실제 영문 캡처에서 랭크업 아이콘은 검출됐고, 기존 한글 글자를 참조하던
보상 사용/계속 탐사 버튼은 검출되지 않아 화면 상태가 미확정이었다.

두 버튼의 참조를 전체 테두리로 확장하고 중앙 글자 영역을 마스킹했다.
기존 한글 캡처의 테두리를 공통 참조로 사용한다. 글자·제목·설명·언어별
OCR에 의존하는 폴백을 추가하지 않는다.

`rank_reward_controls`는 랭크업 아이콘, 문자와 내용물을 제외한 카드 외곽,
하단 계속 버튼 테두리를 함께 확인한다. 아이콘은 카드 내부에 있어야 하고
계속 버튼은 카드 아래에서 중앙 정렬되어야 한다. 카드 안쪽의 사용 버튼은
자신의 테두리가 검출될 때만 반환한다. 랭크업 후 카드가 돌아왔을 때의
기존 계속 탐사 처리도 유지한다. 클릭 직전 재관측과 금지 항목 검사는
기존 경로를 사용하므로 화면이 바뀌면 이전 좌표를 누르지 않는다.

기존 실패 진단에 랭크업 아이콘과 두 버튼의 검출 결과를 추가했다.
별도의 상시 이미지 수집을 추가하지 않는다. 이미지 감사표도 갱신했다.

검증에는 실제 영문 보고 캡처와 기존 한글/이슈 캡처, 제목/설명 제거,
버튼 문자 영역 제거 및 무작위 픽셀 대체, 필수 아이콘/테두리 소실,
다른 보상 화면과의 구분, 클릭 직전 화면 변경을 포함한다. 이벤트 선택
결과에서 랭크업 보상 사용 → 영웅 목록 → 보상 카드 → 지도 복귀를 재생한다.
이 재생에서 영웅 선택과 랭크업 처리는 모의 처리이며 실제 게임 입력은
보내지 않는다. 이번 변경은 랭크업 보상 카드의 인식과 버튼에 한정한다.

검증 결과: 신규 재현 검사와 기존 랭크업 결과/복구 검사를 합쳐 42개 통과.
이미지 감사표 생성, `compileall`, `git diff --check`도 완료했다.
