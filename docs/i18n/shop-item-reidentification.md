# 구매 후 상품 아이콘 재인식 보완

- 작업일: 2026-10-23
- 상태: 저장된 실제 실패 화면을 포함한 회귀 검사 완료 / 수정 후 게임 실행 확인 전
- 관련 작업: [구매 전후 수량 비교](secret-shop-purchase-transition.md), [디버그 기록](shop-debug-logging.md)

## 확인한 장애

16:30:57 세션 1이 두 번째 사이클에서 우정 포인트 구매 후 중지됐다. 디버그 기록의 구매 확인 3회가 모두 `same_item_not_found`였다. 수량 판독과 OCR에는 도달하지 못했다. 저장 화면의 해당 버튼은 `0/1`이었으므로 구매 자체는 완료된 것으로 보인다.

상품 아이콘 전체를 구매 전과 같은 기준으로 찾는 조건이 구매 후의 어두워진 외형·테두리 변화에 취약했다. 기존 아이콘 템플릿과 저장된 구매 후 화면을 대조하면 전체 영역은 약 0.901로 0.95 기준을 통과하지 못하지만 내부 그림은 약 0.964로 통과했다. 실행 당시의 정확한 구매 전 아이콘 픽셀은 남지 않았으므로 이 수치는 저장된 템플릿을 이용한 재현값이며, 당시 내부 비교 점수를 직접 복원한 값은 아니다.

## 변경

1. 구매 전 상품 확인은 기존 전체 아이콘 인식과 사용자 설정 임계값을 유지한다.
2. 구매 후에도 먼저 전체 아이콘을 찾는다. 전체 비교가 실패한 경우에만 테두리·하단 수량·외곽 효과를 제외한 내부 그림을 사용한다.
3. 내부 영역은 폭의 12~88%, 높이의 12~80%로 정하며 원본 면적의 40% 이상과 최소 크기를 요구한다. 82×82 우정 포인트에서는 `[10:72, 10:66]` 영역이다.
4. 내부 비교에서도 0.95 임계값을 유지한다. 검색 가능한 전체 상품 슬롯의 시작 위치는 원래 좌표의 ±24픽셀로 제한하며, 내부 이미지를 잘랐다고 검색 범위를 넓히지 않는다.
5. 확인된 아이콘 이동량만큼 같은 행의 버튼 예상 위치를 이동한다. 내부 그림의 최고점이 전체 아이콘 최고점과 1픽셀 차이가 날 수 있으므로, 해당 버튼의 예상 위치에서 ±3픽셀 안에서만 모양을 다시 정렬한다.
6. 버튼 모양 기준과 같은 상품의 `1/1 → 0/1` 변화 확인은 유지한다. 다른 행의 비활성 버튼을 찾아 완료로 처리하지 않는다.

추가 캡처나 OCR을 요청하지 않는다. 전체 비교가 실패한 경우의 작은 내부 검색과, 이미 확보한 화면에서 버튼을 정렬하는 연산만 추가한다.

사용자가 원인을 오해하지 않도록 상위 중지 메시지의 일률적인 ‘골드 부족 가능성’을 제거하고, 상품 위치·수량·실제 구매 결과를 확인하도록 변경했다.

## 진단 로그

디버그를 켠 경우에만 `item_anchor` 이벤트에 전체/내부 점수, 사용한 영역, 기대 위치와 확정 위치를 기록한다. 구매 완료 이벤트에는 `button_refinement`로 버튼 정렬 이동량을 기록한다. 상품 재인식이 실패하면 구매 전 아이콘과 현재 예상 상품 영역을 기존 화면에서 저장한다.

기록의 인식 방식 ID를 `shop_quantity_transition_v2`로 변경해 기존 v1 기록과 구분한다. 명확하게 구매 완료된 경우에는 추가 증거 PNG를 저장하지 않는다.

## 회귀 자료와 검증

`tests/fixtures/shop_purchase/friendship_sold_20261023.npz`에는 실제 실패 화면의 해당 상품 행과 당시 디버그가 저장한 구매 전 버튼만 넣었다. 계정의 상단 재화 정보 등 관련 없는 화면은 제외했다. 구매 전 아이콘은 원래 화면이 남지 않아 기존 아이콘 자산을 대표 참조로 사용한다.

- 이 자료에서 기존 전체 아이콘 탐색이 실패하고 내부 탐색이 성공함을 확인한다.
- 같은 행의 버튼을 정렬해 `0/1`을 읽고 구매 완료로 판정하며, OCR을 로드하지 않음을 확인한다.
- 아이콘 외곽이 달라져도 내부 그림이 유지된 경우에 같은 임계값으로 찾는지 확인한다.
- 다른 상품·사라진 상품·가려진 화면·다른 행의 같은 아이콘 및 비활성 버튼을 완료 근거로 인정하지 않는지 확인한다.
- 디버그에 내부 점수와 버튼 보정이 기록되고 정상 판정에서 추가 PNG가 만들어지지 않는지 확인한다.

관련 상점·이미지·진단·GUI·배포 검사를 포함해 111개 검사가 통과했다. 정상 구매 재현의 캡처 횟수는 기존과 동일하게 4회이며, 저장된 실패 행의 구매 완료 확인에는 OCR을 사용하지 않았다.

저장 화면에 대한 재현 결과이며, 수정 후 실제 게임에서 구매·반복 실행을 수행한 결과는 아니다. 다른 아이템이나 게임 패치의 모든 외형 변화를 보장하지 않으며 새 디버그 기록으로 확인해야 한다.
