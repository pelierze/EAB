## 휴식 화면과 입력

고정된 두 배경 조각과 오른쪽 메뉴 4개의 배치를 함께 확인한다.

| 용도 | 원본 기준 영역 `[x,y,w,h]` | 제외한 내용 |
|---|---|---|
| 왼쪽 고정 배경 | `[250,235,90,65]` | 깃발·모닥불·영웅 바깥 |
| 텐트 오른쪽 지붕 | `[700,230,80,50]` | 깃발 아래, 모닥불·영웅 위 |
| 최상단 메뉴 | `[905,148,330,94]` | 내부 `[20,20,290,58]`의 문구 |
| 나머지 메뉴 | x=905, y=258/368/478, 폭 330, 높이 94 | 같은 문구 영역 |

참고 원본은 `rest_menu_local_live.png`, 완료·비활성 프레임은 `rest_completed_live.png`다. 고정 배경과 메뉴 프레임을 실제 영어 오류 화면에서도 확인했다. 흔들리는 깃발, 모닥불과 영웅 영역은 비교에 사용하지 않는다. 테스트에서는 이 영역들을 무작위 픽셀로 바꾸어 인식 결과가 유지되는지 검사한다.

나머지 세 메뉴는 부상·사망 여부에 따라 활성 상태가 달라지므로, 해당 위치의 기존 프레임 또는 공통 활성 프레임의 회색조 모양만 확인한다. 이 세 메뉴의 밝기·색차는 최상단 활성 판정의 근거가 아니다. 활성 상태 변경은 밝기 변환과 공통 활성 프레임 배치로 모의 검사했다.

최상단은 활성 프레임이 확인되고 완료 체크가 없을 때만 선택한다. 버튼 가운데를 눌러 `rank_menu` 전환을 기다린다. 고정 좌표만 반복 입력하지 않는다. 나가기에는 글자를 제외한 기존 공통 보라색 버튼을 사용한다. 휴식 화면을 먼저 확인하므로 같은 모양의 다른 화면 버튼만으로 휴식 동작을 실행하지 않는다.

랭크업 후에는 실제 완료 체크를 확인해야 나간다. 단순히 랭크업 문구가 사라졌다는 이유로 나가는 이전 조건은 제거했다. 비활성 프레임과 활성 프레임을 각각 비교하며 고정 채도값으로 메뉴를 구분하지 않는다.

## 랭크업 영웅 목록

- 한글 제목 대신 왼쪽 패널의 테두리, 탐사 하단 아이콘, 파티 직업 아이콘의 조합으로 목록을 구분한다. 패널 내부 제목·상세 능력치·영웅 이름은 제외한다.
- 직업 아이콘 위치 조사와 랭크 숫자 OCR을 분리해, 화면 분류에는 OCR을 추가하지 않는다. 같은 직업이 중복 검출되면 확정하지 않는다. 영웅 이탈 후 파티 인원이 줄어든 목록도 허용한다.
- 선택한 직업의 카드에서 금색 테두리 세 면을 확인하고 활성 랭크업 버튼의 글자를 제외한 테두리를 확인한다. 선택되지 않은 목록이나 다른 직업의 선택 상태로 확정하지 않는다.
- 기존 숫자/MAX 판독과 우선순위 정책은 유지한다. 기존 파티는 직업당 한 명이라는 전제도 유지한다.

## 기록·검증 범위

실제 영어 오류 화면은 `tests/fixtures/exploration/english_rest_menu_20261024.npz`의 `screen`에 보존했다. 원본은 `logs/report/20261024_213111_679066_세션_1_d0ef9bca/screen.png`이다.

기본 실패 보고서에도 고정 배경·활성/비활성 메뉴 프레임·완료 체크·나가기·랭크업 화면/버튼의 검출 결과를 추가했다. 상세 점수 기록은 기존대로 디버그 모드에서만 생성한다. 추가 캡처나 대기 시간은 넣지 않았다.

검사는 실제 영어 휴식 화면, 기존 한글의 활성/완료 화면, 깃발·모닥불·영웅 영역 변경, 문구 변경, 구조/고정 배경 누락, 완료 체크 누락, 잘못된 선택 테두리, 파티 인원 감소를 포함한다. 실제 화면 재생으로 최상단 → 대상 영웅 → 랭크업 → 결과 닫기 → 완료 확인 후 나가기의 입력 순서도 확인한다. 게임에는 입력을 보내지 않는다.

영어 랭크업 목록·결과·완료 화면은 아직 실제 캡처가 없다. 목록은 기존 한글 화면의 제목·이름·버튼 문구를 제거해 검사했고, 영어 완료 화면은 영어 휴식 원본에 기존 완료 프레임과 체크를 합성한 시험 화면이다. 이 재생 검사를 실제 영어 완주 확인으로 취급하지 않는다.

비교 영역 미리보기: [이미지 감사표](exploration-image-audit.html).

## 검증 기록

- 노드·보상·복구·영웅 이탈·배포 회귀 184개 실행에서 183개 통과, 기존 모의 검사 1개가 새 선택 테두리 확인 조건을 제공하지 않아 시간 초과했다 (`logs/exploration-rest-menu-regression.log`). 실제 영웅 목록 대신 보상 화면과 가짜 영웅을 쓰는 결과 처리 전용 검사였다.
- 해당 모의 검사에 선택 확인 결과를 명시하고 대기 제한을 줄인 후 휴식·랭크업 관련 30개 재검사 통과 (`logs/exploration-rest-rank-final.log`).
- 다른 세 메뉴의 활성/비활성 변화를 허용하는 최종 모양 검사 후 휴식·배포 관련 28개 통과 (`logs/exploration-rest-menu-final.log`). 위 검사와 중복되므로 고유 검사 수로 합산하지 않는다. 전체 184개 실행 자체가 모두 통과한 것으로 집계하지 않는다.
- `python -m compileall -q src/chaos`, `git diff --check` 통과.
