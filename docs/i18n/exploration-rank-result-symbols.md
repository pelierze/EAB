# 랭크업 결과 화면의 언어 독립 판별

2026-10-25 20:26:27 보고에서는 휴식 노드의 랭크업 실행 후 결과창을
닫기 직전 판별이 세 번 실패해 중지했다. 저장 화면의 전환 화살표는
검출되지만 기존 `RANK UP` OCR이 `TRANKUS`를 반환해 결과창 판별이
실패하는 것을 재현했다. 실제 화면 전환이 없어도 이 판별 불안정이
`클릭 직전 화면 변경`으로 기록될 수 있었다.

랭크업 결과의 문자 OCR과 유사 문자열 비교, 전용 문자 영역 설정을
제거했다. 대신 전환 화살표와 그 양쪽의 랭크 마크만 확인한다.
능력치 패널 테두리와 내부는 판별하지 않는다. 숫자와 `Max` 표시도
참조 범위에서 제외한다. 영웅의
초상화, 이름, 왼쪽의 빛나는 글자, 하단 닫기 안내 문구를 읽지 않는다.

같은 가로 띠(x=710~1030, y=205~255)에서 공통 랭크 마크가 정확히 두 개,
화살표가 정확히 한 개 검출되어야 한다. 마크 → 화살표 → 마크 순서와
수평 정렬을 확인하며 숫자 폭에 따른 가로 간격 변화는 허용한다.
닫기는 기존 고정 영역을
사용하며 안정 관측과 클릭 직전 재판별을 유지한다. 전환 화살표만 있는
불완전한 화면은 전리품 결과창으로 넘기지 않고 대기한다. 클릭 직전
마크가 사라지면 이전 좌표로 입력하지 않는다.

실패 진단에는 화살표, 검증된 좌우 마크, 닫기 가능 여부를 기록한다.
별도의 상시 이미지 수집은 추가하지 않았다. 이미지 감사표를 갱신했다.

검증은 최신 영문 오류 캡처와 기존 휴식/이벤트 결과 캡처, 문자·초상화·
능력치 숫자 제거, 개별 표식 소실, 다른 등록 화면의 오인 여부를 포함한다.
기존의 문자 OCR 정확도 검사는 새 문자 비의존 검사로 교체한다. 결과창
닫기 재생에서는 OCR 호출을 금지하고 클릭 횟수와 후속 화면을 확인한다.
실제 게임 입력은 보내지 않는다. 새 게임 패치로 마크나 화살표의 모양 및
표시 높이가 바뀌는 경우에는 참조 검토가 필요하다.

회귀 검사를 합쳐 40개 통과. 이미지 감사표 생성, `compileall`,
