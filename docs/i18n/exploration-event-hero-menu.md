# 이벤트의 공통 영웅 선택과 실제 후속 화면 처리

2026-10-26 사용자 요청에 따라 이벤트 안에서 이탈·랭크업 목록을 미리
구분하지 않고 무작위 영웅을 선택한다. 휴식 노드의 기존 랭크업 우선순위는
유지하며, 이벤트 흐름 안에서만 공통 `event_hero_menu` 분류를 적용한다.

후보는 각 행의 직업 아이콘과 그 아래 랭크 마크로 찾는다. 같은 직업이
여러 행에 있어도 행마다 별도 후보로 취급한다. 실제 보이는 행만 반환하며,
목록 패널 외곽과 탐사 하단 아이콘으로 다른 카드 화면을 제외한다. 확인창의
버튼 쌍이 남아 있으면 뒤쪽 목록을 후보로 노출하지 않는다. 제목, 영웅 이름,
랭크 숫자, 이탈/랭크업 버튼 글자와 OCR은 사용하지 않는다. 기존 한글
이탈 제목과 실행 문구를 참조하던 마커를 제거했다.

안정 관측 후 후보 하나를 무작위로 고르고, 금색 선택 테두리·동일 초상화·
글자를 제외한 실행 버튼 테두리를 재검사한다. 활성/비활성 버튼을 별도로
비교해 비활성 후보는 한 번만 시도한 뒤 제외한다. 후보가 모두 비활성이면
추가 실행 없이 중지한다. 목록이나 선택이 바뀌거나 버튼 상태가 모호하면
이전 좌표로 실행하지 않는다.

검증한 영웅 실행 직후에만 글자 없는 취소/승인 버튼 쌍의 승인을 허용한다.
승인 직전 좌표를 재확인하고, 승인 후 버튼 쌍 소실 및 실제 후속 화면을
관측한다. 일반 이벤트 선택 직후의 취소 정책과 서로 다른 처리 구간이다.
영웅 실행 이력이 없는 팝업을 이 처리로 승인하지 않는다.

랭크업 결과는 공통 마크/화살표 판별 및 닫기로 연결된다. 결과 뒤 랭크업
보상 카드가 돌아오면 기존 완료 후 계속 탐사 경로를 사용해 다시 영웅을
선택하지 않는다. 지도·대화·다른 보상도 각각 기존 처리로 이어진다.
실제 결과를 확인할 수 없으면 실행이나 승인을 반복하지 않고 중지한다.
실행 종류를 추정해 이탈 수를 늘리지 않고 `event_hero_actions`를 기록한다.
실패 진단에는 랭크 마크와 버튼 상태를 추가하며 상시 캡처는 추가하지 않는다.

검사는 기존 이탈/랭크업 캡처, 제목·이름·버튼 문구 삭제, 직업/랭크 마크
누락, 동일 직업의 여러 행, 영웅 수 감소, 금색 테두리·초상화 변경, 비활성
후보 제외, 후보 소진, 실행 후 승인/결과/지도 및 랭크 보상 복귀를 포함한다.
실제 활성 이탈 버튼과 이탈 후 확인창의 전용 캡처는 아직 없으므로, 선택
테두리는 합성하고 활성 버튼은 실제 랭크업 버튼에서 가져왔다. 확인창
재생에는 기존 공통 팝업 캡처를 사용한다. 실제 게임 입력은 보내지 않는다.
실제 이탈 전용 활성 버튼의 외형이 공통 버튼과 다르면 추가 참조가 필요하다.

검증 결과: 공통 영웅 선택 16개와 기존 랭크 보상/결과, 이벤트 흐름 및
일반 선택 직후 취소 검사를 합쳐 69개 통과. 이미지 감사표 갱신,
`compileall`, `git diff --check`도 완료했다.
