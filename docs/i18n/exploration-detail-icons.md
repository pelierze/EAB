# 탐사 노드 상세 화면의 아이콘 인식

후속: [휴식 내부 메뉴와 랭크업의 문자 제외 인식](exploration-rest-menu.md).

- 날짜: 2026-10-24
- 브랜치: `codex/i18n-dimensional-exploration`
- 관련 오류: 17:34:42 탐사 중단 보고서. 전투 완료 후 영어 휴식 상세 화면을 지도로 분류하고 `rest_detail`을 기다리다 시간 초과했다.

## 변경

일반 전투·휴식·보급·정예 전투·보스·이벤트의 상세 제목 비교를 오른쪽 상단의 종류별 아이콘으로 바꿨다. 기존 원본에서 `[1210,96,45,40]`을 잘라 `[1200,85,70,65]` 안에서 비교한다. 기존 유사도·색차 기준은 유지한다.

확인된 아이콘이 한 종류일 때만 해당 상세 화면으로 판정한다. 영어 진입 버튼은 글자를 제외한 공통 버튼 테두리와 이 아이콘을 함께 확인한다. 이전에는 일반 전투 아이콘에만 연결되어 있던 버튼 인식을 6종에 연결했다. 기존 한글 진입 버튼 경로도 호환성을 위해 유지한다.

상세 아이콘이 있지만 버튼을 확인할 수 없거나, 종류를 확인하지 못한 상세 패널의 버튼이 지도 위에 남아 있으면 지도로 분류하지 않는다. 이전 화면의 좌표로 다른 노드를 누르는 대신 인식 대기를 유지한다. 컨트롤러는 선택한 노드 종류와 실제 상세 화면 종류가 일치해야 다음 단계로 진행하는 기존 조건을 유지한다.

기본 실패 보고서에도 진입 버튼·공통 테두리·6종 상세 아이콘의 검출 결과를 추가했다. 상세 디버그 점수 기록은 기존대로 디버그 모드에서만 생성한다. 추가 캡처나 대기 시간은 넣지 않았다.

## 근거와 범위

사용자가 실제로 실행하다 중단된 영어 휴식 화면을 `tests/fixtures/exploration/english_rest_detail_20261024.npz`에 보관했다. 원본은 `logs/report/20261024_173442_158401_세션_1_30b8995c/screen.png`이다. 이 화면의 휴식 아이콘은 기존 한글 원본과 유사도 약 0.99999, 평균 색차 약 0.00128로 일치했다. 새 판정은 `rest_detail`이며 진입 영역은 `(939,629,300,64)`다.

일반 전투·휴식의 실제 영어 캡처를 확인했다. 다른 4종은 기존 한글 화면의 제목·설명·진입 문구를 바꿔 문자에 의존하지 않음을 검사한 것이며 실제 영어 캡처 검증과 구분한다.

아이콘이 없는 내부 선택지, 랭크업 화면 제목·영웅 이름, 상점·이벤트의 개별 선택 문구는 이번 변경으로 모두 공통화된 것이 아니다. 휴식 내부 화면과 나머지 흐름은 계속 실사용 기록으로 확인해야 한다. 상점 상세의 종류 아이콘은 참고 화면이 없어 새 공통 인식에 추가하지 않았다.

## 검사

- 실제 영어 휴식 오류 화면의 상태·진입 버튼 검출.
- 6종 상세에서 제목·설명·진입 글자를 제거해도 올바른 종류로 분류.
- 아이콘 누락·종류 충돌·중복 후보 거부, 비활성/누락 버튼에서 지도 오인 방지.
- 지도 → 실제 영어 휴식 상세 → 기존 휴식 내부 화면을 재생하며 입력은 두 번만 요청하는지 검사. 게임에는 입력하지 않는다.
- 기본 실패 보고서의 상세 종류와 진입 근거 기록.
- 기존 노드·복구·이벤트 진입·영어 전투·배포 관련 회귀 검사.

최종 관련 검사 125개 통과: `logs/exploration-detail-icons-final.log`.
최초 문자 제거 검사에서는 버튼의 실제 위치보다 1픽셀 위·왼쪽을 지워 테두리까지 손상시킨 테스트 준비 오류가 있었다. 실제 검출된 버튼 위치에 맞춰 제외 영역만 바꾸도록 수정한 후 위 검사를 실행했다.
