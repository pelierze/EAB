# 탐사 일시 정지와 현재 화면부터 재개

2026-10-27 요청에 따라 탐사 탭에 `⏸ 일시정지`와 `▶ 재개`를 추가한다.
영어 UI에서는 `⏸ Pause`와 `▶ Resume`이다. 버튼과 상태·사용 안내는 기존
언어 변경 경로에서 즉시 번역된다.

사용 순서:

1. 탐사 중 일시정지를 누른다. 상태가 '요청 중'이면 아직 다른 조작을 기다린다.
2. '일시 정지 중'이 표시되면 봇의 입력과 관측이 멈춘 상태다. 게임에서 다른
   작업을 수동으로 진행할 수 있다. 게임 자체를 정지하는 기능은 아니다.
3. 진행 중이던 탐사 화면으로 돌아와 재개를 누른다. 새 화면을 판별해 이어간다.
4. 정지 중에도 중지 버튼으로 봇 실행을 종료할 수 있다.

일시 정지는 캡처·관측·입력 전의 공통 체크포인트에서 승인된다. 이미 전송한
게임 입력을 취소할 수는 없으므로 작업을 바꾸기 전에 완료 상태를 확인해야
한다. 승인된 정지 동안에는 캡처나 ADB 입력을 보내지 않는다.

재개는 멈춰 있던 함수의 다음 줄을 실행하지 않는다. 내부 제어 신호로 기존
핸들러를 빠져나와 새 모집/노드 처리기를 만든 뒤 현재 화면을 다시 확인한다.
선택 좌표·승인 대기 상태·현재 노드 추정·거부한 후보 등 일시 상태는 버린다.
이벤트 중이었다는 이력은 설명/결과 화면을 복구할 수 있도록 유지하되, 새로
확인된 노드의 종류를 사용한다. 라운드·완주·실패·확인한 노드·입력 수와
자동 전투 확인 이력은 유지한다. 정지 시간은 새 관측 제한 시간에 포함되지
않으며 재개만으로 회차나 완료 횟수를 늘리지 않는다.

정지 중에는 세션을 실행 중으로 유지해 같은 세션에서 다른 자동화를 동시에
시작하지 않는다. 이 기능은 현재 실행 중인 프로세스 안에서의 일시 정지이며
앱 종료 후 상태 저장/복구 기능은 아니다. 재개 시 탐사와 무관한 화면에 있으면
그 화면을 임의로 클릭하지 않고 기존 인식 대기/중지 조건을 따른다.

검증은 정지 승인 이후 입력 없음, 재개 후 이전 클릭 폐기, 정지 중 중지,
입력 직전 정지 요청, 화면 재판별, 회차/완주 수 유지, 이벤트 결과 복구와
한글/영문 버튼 및 요청/완료 상태를 확인한다. 실제 게임 입력은 보내지 않는다.

검증 결과: 정지/재개 7개, UI 번역/상태 5개, 기존 완주·반복 17개,
인식 복구 14개, GUI 수명주기 10개, 이미지 패키지 6개로 총 59개 통과.
`compileall`과 변경 파일의 `git diff --check`도 완료했다.
