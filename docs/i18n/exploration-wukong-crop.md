# 불사형 오공 영입 목록 초상화 범위

2026-10-25 15:17:24 보고에서는 영문 전사 목록 오른쪽 두 번째 줄에
Immortal Wukong이 보였으나, 기존 초상화 비교가 이름 겹침의 영향을 받아
최대 일치도 약 0.861로 기준 0.90에 미달했다.

기존 132×45 참조에서 왼쪽 48픽셀을 제외한 오른쪽 84×45만 사용한다.
원본 파일은 유지하고 `recruitment_layout.json`의 crop으로 적용한다.
기준 0.90과 색상 오차 제한은 유지한다. 실제 오류 화면에서는 새 범위의
최대 일치도가 약 0.973이며, 선택 전 목록 스크롤 없이 검출된다.

오른쪽 끝과 y 위치를 보존했으므로 초상화의 오른쪽 끝으로 카드 위치를
계산하는 금색 선택 테두리 검사도 유지된다. 카드가 선택되지 않은 화면에서는
검출만으로 영입 버튼을 누르지 않는다.

실제 영문 캡처, 제외한 이름 영역 변경, 초상화 제거, 스크롤 없는 검출과
기존 영웅별 선택 테두리·영입 재시도 검사를 포함해 17개 테스트가 통과했다.
실제 게임 입력은 전송하지 않았다. 유효 이미지 영역 감사표도 갱신했다.
