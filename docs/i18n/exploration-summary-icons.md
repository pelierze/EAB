# 종료 정산 화면의 아이콘 판별

2026-10-25 15:07:17 오류 보고는 보스전 뒤 영문 정산 화면이 표시됐지만,
한글 제목을 찾던 판별이 실패해 전투 제한 시간에 도달한 사례다. 닫기의
X 아이콘은 정상 검출됐다.

정산 화면 판별을 제목 대신 노드(교차 검), 영웅(투구), 파편, 전리품의
고정된 통계 아이콘 네 개와 닫기 X 조합으로 바꾼다. 참조는 기존 한글
정산 이미지의 아이콘이며, 숫자·제목·설명 문구는 참조에서 제외한다.
각 아이콘은 제한된 위치에서 유일하게 검출되어야 한다. 결과 화면을
흉내 내는 단일 아이콘만으로 일반 승리/보상 화면을 닫지 않는다.

정산 화면 감지와 완주 판정은 별개다. 기존 보스 처치 숫자 판독과
정확한 3마리 조건, 패배 기억 우선 처리, 숫자 불확실 시 정산창 유지,
닫힌 뒤 탐사 초기 화면 확인은 유지한다. 중앙 아이콘만으로 완주를
집계하지 않는다. 실제 보고된 영문 화면에서는 숫자 3을 정상 판독했다.

검사는 실제 영문 캡처, 제목/문구 제거, 개별 통계 아이콘·닫기 누락,
일반 승리·영입·전리품 화면과의 구분, 보스전에서 정산 화면으로 직접
넘어간 뒤 닫기와 완주 집계까지의 재생을 포함한다. 초기 화면은 기존
한글 참조를 사용하며 실제 게임에 입력은 보내지 않는다. 기존 미완주·
패배·반복 실행 검사도 함께 수행한다.

기존 실패 진단에 네 통계 아이콘과 닫기 검출 결과를 추가한다.

검증 결과: 영문 정산과 기존 완주·미완주·패배·반복 흐름의 23개 테스트 통과.
이미지 감사표 갱신, `compileall`, `git diff --check`도 완료했다.
