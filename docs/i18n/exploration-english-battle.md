# 차원 탐사 영어 지원: 진입·전투와 디버그 기록

- 날짜: 2026-10-24
- 브랜치: `codex/i18n-dimensional-exploration`
- 영어 UI의 탐사 탭을 활성화했다. 미제공 화면은 기존 인식으로 실행하면서 기록으로 보완하는 단계이며 영어 전체 완주 검증은 아직이다.

기존 한글 인식 경로를 유지하며, 실패하면 글자를 제외한 이미지와 별도 화면 단서를 조합한다.

- 초기 화면: 시작 버튼 테두리 + 보관소 아이콘.
- 전투 준비: 버튼 테두리 + 좌측 하단 배치 아이콘.
- 일반 전투 상세: 버튼 테두리 + 상세 패널의 교차 검 아이콘.
- 승리: 기존 VICTORY 제목 + 가운데 계속 탐사 버튼 테두리.
- 레벨업: 숫자를 제외한 원형 패널 + 하단 닫기 화살표.
- 그림자 로제: 기존·새 화면의 초상화에서 이름 끝부분이 겹치는 왼쪽 30픽셀을 제외했다. 오른쪽 끝과 세로 위치를 유지해 금색 선택 테두리 확인 조건도 유지한다. 기존 전체 참고 파일은 보존한다.

보라색 버튼만으로 화면을 분류하지 않는다. 나머지 영웅과 노드는 기존 참고 이미지를 사용한다. 배포에는 전체 원본 대신 필요한 크롭을 포함한다.

## 디버그 사용법

1. **디버그 모드 (상세 로그)**를 켜고 탐사를 시작한다.
2. 일반 로그의 `탐사 디버그 기록:` 경로를 확인한다.
3. 멈추면 그 `debug` 폴더와 일반 실행 로그를 함께 확인한다.

경로는 `logs/<세션 ID>/chaos_recruitment_<실행 ID>/debug/`다. 반복 회차에서도 같은 디버그 폴더를 사용한다.

- `recognition.jsonl`: 단계·관측 결과·안정화 횟수·인식 보류 사유·화면 상태·입력 위치·최종 결과.
- `failure_XX.png`: 실패 시 마지막으로 읽은 정규화 화면.
- `failure_XX.json`: 단계·사유·선택 영웅·선택 대상·노드, 마커별 점수·색차·허용 기준·후보 위치·최종 승인 위치.

점수는 **기본 참고 이미지(primary)** 기준이다. `accepted_bounds`는 대체 초상화·화면 단서·중복 후보 배제 등을 포함한 실제 최종 결과다. 두 값은 다를 수 있다. 인식 중 오류는 해당 마커의 `recognition_error`에 남긴다.

로그 파일은 2 MB씩 원본과 백업 2개로 순환하고 실패 화면은 실행당 최대 12개다. 연속 동일 관측은 중복 기록을 줄인다. 파일 저장 오류는 일반 로그에 남기고 봇은 계속 실행한다.

디버그를 끄면 새 기록기는 생성하지 않고 추가 점수 조사·화면 저장을 하지 않는다. 기존 기본 실패 진단과 이벤트 제보 옵션은 별도로 유지한다. 켠 경우에도 추가 캡처나 대기 없이 기존 화면을 사용하지만 파일 기록과 실패 시 상세 조사 비용은 발생한다. 실제 게임 1사이클 시간은 측정하지 않았다.

## 검증 범위와 남은 작업

새 화면의 상태·영웅 선택·속성 선택, 문자 변경, 잘못된 화면의 공유 버튼 거부, 배포 자산, 디버그 기본 비활성·중복 생략·저장 오류 처리를 검사했다. 실제 화면 재생으로 지도 → 전투 상세 → 준비 → 레벨업 닫기 → 승리 후 지도 복귀도 검사했다. 전투는 생략하며 게임 입력은 보내지 않았다.

영어 휴식·보급·상점·이벤트·영웅 보상·랭크업·최종 정산·재진입은 아직 확인하지 않았다. 기존 이미지로 인식되지 않으면 인식 대기 후 중지하는 기존 정책에 따라 기록을 모은다. 영입 전체 영웅 조합도 실사용 확인이 필요하다.

UI 테스트의 디버그 설정값 누락으로 실제 오류 창이 노출된 문제는 테스트 설정을 보완하고 오류 창 호출을 모의 처리해 수정했다.

검증 기록:

- 영어 화면·디버그·UI·언어 검사 73개 통과 (`logs/exploration-ui-final.log`). 화면 재생 검사를 포함하며 팝업 모의 처리를 적용한 최종 실행이다.
- 초상화의 문자 겹침 제거 후 영입·선택 테두리·영어 화면·배포 관련 87개 재검사 통과 (`logs/exploration-final-portrait.log`). 앞선 검사와 중복되므로 합산하지 않는다.
- 기존 랭크업 완료 검사의 한글 계속 탐사 문구 필수 조건을 버튼 자체의 존재 조건으로 갱신했다. 글자만 지워도 인식하고 버튼 자체를 지우면 거부하는 검사와 함께 관련 21개 통과 (`logs/exploration-rank-final.log`).
- 전체 탐사·배포 회귀 실행은 388개 중 387개 통과, 위의 오래된 한글 문구 필수 기대값 1개가 불일치했다 (`logs/exploration-battle-regression-final.log`). 해당 기대값 수정 후 21개 재검사는 통과했으며 다른 실패는 없었다. 전체 실행 자체를 모두 통과한 것으로 집계하지 않는다.
- `python -m compileall -q src/chaos src/gui.py`, `git diff --check` 통과.
