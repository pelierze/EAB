# 이벤트 결과 화면의 애니메이션 허용

2026-10-25 16:16:02 미믹 이벤트 보고에서는 전리품 소모와 보상창 닫기는
성공했지만 결과 설명의 진행 화살표를 누르기 직전에 중지됐다. 기존 검사는
본문/배경의 정확한 픽셀 해시와 화살표 좌표가 모두 같아야 했다.

안정 관측은 결과 화면 종류, 선택지 없음, 진행 화살표 존재를 기준으로 한다.
클릭 직전 다시 캡처해 같은 조건을 확인하고 그 프레임의 화살표 좌표를 쓴다.
해시/좌표의 작은 변화만으로 다른 화면이라고 단정하지 않는다. 선택지·경고·
보상 등 다른 후속 화면이 나타나면 입력 없이 재관측해 전용 처리로 넘긴다.
화살표가 없거나 화면 변화가 반복되면 이전 좌표로 클릭하지 않는다.

클릭 후 같은 페이지를 반복해서 누르지 않는 조건도 유지한다. 배경 삽화와
화살표를 제외한 본문 영역의 밝은 획을 축소/비교하며 작은 고립 입자와
약간의 렌더링 차이를 허용한다. 단어·언어·문장의 의미를 판독하는 OCR은
사용하지 않는다. 알려진 서로 다른 결과 표식 또는 충분한 본문 변화가
확인되거나 다른 종류의 화면으로 전환되어야 다음 단계로 인정한다.
전환이 불명확하면 추가 입력 없이 대기하다 중지한다.

기존 선택지 판별용 `_event_signature`는 바꾸지 않았다. 이 보완은 결과
화면의 클릭 전 확인과 클릭 후 페이지 전환 확인에 적용된다.

실제 영문 미믹 결과 캡처에 이동한 화살표·배경 입자·본문 변화 등을 합성해
검사한다. 클릭 직전 선택지 등장/화살표 소실, 같은 페이지의 애니메이션만
남은 경우 추가 클릭 방지와 실제 지도 복귀도 재생한다. 실제 게임 입력은
보내지 않는다.
