# 일반 이벤트 선택 직후의 버튼 쌍 취소

2026-10-25 22:39:47 보고는 일반 이벤트 선택 후 경고창이 나타났지만
상단 테두리 검출률이 80% 미만이어서 중지한 사례다. 실제 캡처의 글자를
마스킹한 취소·승인 버튼은 모두 정상 검출됐다.

일반 이벤트 선택지를 안정 관측하고 클릭한 직후의 `_event_transition`에만
`choice_warning=True`를 전달한다. 이 구간에서는 문자 영역을 제외한 버튼
쌍과 기존 상대 배치(215픽셀 간격, 같은 높이)를 확인하면 `event_warning`으로
처리한다. 상·하단 테두리나 제목·설명·버튼 글자를 판독하지 않는다.
전역 화면 분류의 경고창 조건은 변경하지 않는다.

취소 입력 직전에도 두 버튼을 다시 찾아 같은 취소 위치인지 확인한다.
입력이 가능한 경우에만 직전 선택지를 거부 목록에 추가하고 왼쪽 취소를
누른다. 버튼 쌍이 사라진 뒤 인식 가능한 후속 화면을 확인한다. 선택지
화면으로 돌아왔으면 거부 목록을 유지하고 공통 이벤트 흐름에서 나머지
허용 후보를 선택한다. 후보가 없으면 추가 입력 없이 중지한다. 다른 보상
화면 등으로 실제 전환되면 기존 후속 화면 처리로 넘긴다.

이 버튼 쌍 폴백은 일반 선택 직후에만 유효한 함수 인자이며 전역 상태로
유지하지 않는다. 영웅 이탈·전리품 소모·보상 처리 등 별도 단계의 확정
절차에는 적용하지 않는다. 재개한 팝업에 선택 직후 이력을 추정해서
취소하지 않는다. 별도의 상시 캡처나 로그 수집도 추가하지 않는다.

검증은 최신 실제 캡처, 문구/패널 없는 버튼 쌍, 버튼 누락/중복, 일반 선택
직후에만 작동하는 범위, 취소 후 팝업 소실 확인, 선택지 제외 및 대안 선택,
클릭 직전 화면 변화, 후보 소진 시 입력 중지를 포함한다. 전용 영웅 이탈
및 기존 이벤트 경고/선택 재시도 회귀 검사도 함께 실행한다. 재생은 실제
게임 입력을 보내지 않는다.

영웅 이탈 검사 총 59개 통과. `compileall`, `git diff --check` 완료.
