# 직업 영입권: 아이콘과 카드 구조 인식

- 날짜: 2026-10-24
- 브랜치: `codex/i18n-dimensional-exploration`
- 실제 오류: 22:19:29, 이벤트 결과의 영어 정령사 영입권 화면을 인식하지 못해 선택 결과 대기가 시간 초과했다.

## 변경

중앙 영입권 카드의 외곽, 파란 영입 버튼의 외곽, 아래 계속 탐사 버튼의 외곽을 확인한 뒤 정해진 카드 상단 영역에서 직업 아이콘을 찾는다. 직업 아이콘 하나가 목록이나 지도에 보인다는 이유만으로 영입권으로 분류하지 않는다. 두 종류 이상의 직업이 동시에 일치하면 확정하지 않는다.

- 카드: `[514,114,252,426]`, 내부 `[14,14,224,398]` 제외.
- 파란 영입 버튼: `[535,454,212,55]`, 내부 `[18,8,176,38]` 제외.
- 계속 탐사: `[473,615,334,75]`, 내부 `[28,8,278,58]` 제외.
- 직업 아이콘 탐색: `[585,145,115,110]`.

아이콘은 회색조 모양으로 비교한다. 기사·전사·도적·정령사는 기존 영입 시작 화면의 80×80 아이콘, 사수는 기존 영입권 원본의 80×80 아이콘을 사용한다. 크기 차이를 고려해 0.90/0.95/1.00/1.05배를 비교한다. 실제 영어 정령사 화면은 기존 정령사 참고를 0.95배로 비교할 때 약 0.997의 모양 유사도로 일치했다.

마도사는 제공된 영어 필터 패널의 문구 없는 30×30 아이콘을 참고 이미지로 추가하고 2.25/2.375/2.50/2.625배로 비교한다. 실제 마도사 영입권은 아직 제공되지 않아 합성 카드에서만 확인했다. 감사표에도 비교 배율을 기록한다.

직업 아이콘이 없는 전체 직업 영입권 등 기존 한글 화면의 호환성을 위해, 카드·버튼 3종이 확인되고 기존 한글 영입 문구가 일치하는 경로를 유지했다. 영어 전체 직업(All) 영입권은 이번 실제 캡처의 검증 범위가 아니다.

## 진행 정책과 확인창

기존 파티 구성 정책을 유지한다. 추가 영웅을 영입하거나 파란 버튼을 누르지 않고 아래 **계속 탐사**를 눌러 건너뛴다.

그 입력을 확인한 직후에만 건너뛰기 확인창의 확인·취소 버튼 외곽을 비교한다. 기존 한글 버튼 판독이 실패하면 문구를 제외한 두 버튼을 함께 확인하며, 좌우 간격과 높이 정렬도 검증한다. 어느 한 버튼만 있거나 클릭 직전 화면이 바뀌면 확인을 누르지 않는다.

이 문구 제외 확인 버튼은 전역 `story_confirm`/`story_cancel` 인식에 연결하지 않았다. `_recruit_skip_confirmation_pending`이 활성화된 기존 건너뛰기 처리 안에서만 사용한다. 계속 탐사 입력이 실패하면 이 확인을 허용하지 않으며, 다음 화면으로 넘어가거나 중단하면 대기 상태를 해제한다.

## 자료와 검증 범위

실제 영어 정령사 화면은 `tests/fixtures/exploration/english_recruit_ticket_20261024.npz`의 `screen`에 보존했다. 원본은 `logs/report/20261024_221929_282738_세션_1_347b9fad/screen.png`다. 기존 한글 사수 영입권도 함께 확인했다.

6종 직업 검사는 참고 아이콘을 실제 영어 카드의 아이콘 자리에 합성한 시험이다. 6종 모두의 실제 영어 영입권을 확인한 것은 아니다. 확인창 역시 기존 한글 확인창의 버튼 문구를 제거한 시험이며 실제 영어 확인창 캡처와 구분한다.

검사는 문구 변경, 카드·아이콘·버튼 누락 거부, 랭크업 등 다른 보상 화면 거부, 확인·취소 쌍의 필요성, 영어 영입권 → 문구 없는 확인창 → 지도 재생을 포함한다. 게임에는 입력을 보내지 않는다.

기본 실패 보고서에도 카드·버튼·직업 아이콘·건너뛰기 확인 버튼 검출 결과를 추가했다. 상세 점수는 기존대로 디버그 모드에서만 기록한다. 기본 참고의 점수와 배율을 적용한 최종 승인 결과는 다를 수 있으므로 `accepted_bounds`와 함께 해석한다. 추가 캡처·대기·OCR은 넣지 않았다.

검증: 영입권·건너뛰기 확인·이벤트·랭크업·복구·보상·배포 회귀 114개 통과 (`logs/exploration-recruit-ticket-regression.log`). 기존 한글 호환 경로와 아이콘 모호성 거부를 추가한 영입권 전용 최종 10개도 통과했다 (`logs/exploration-recruit-ticket-final.log`). 검사끼리 중복되므로 합산하지 않는다. `python -m compileall -q src/chaos`, `git diff --check` 통과.
