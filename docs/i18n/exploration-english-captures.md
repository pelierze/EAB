# 차원 탐사 영어 캡처 적용: 2차 작업

- 날짜: 2026-10-24
- 브랜치: `codex/i18n-dimensional-exploration`
- 범위: 고용 서약서 선택, 영입권·영입 완료 화면, 필터 버튼·열린 패널, 탐사 입장 버튼, 노드 지도.
- 상태: 제공된 화면 기반 구현·재현 검사. 영어 탐사 전체 기능의 실기 검증은 아직 하지 않음.

스티그마 이후 추가된 9개 파일과 작업 중 추가된 열린 필터 패널을 모두 사용했다.

## 변경한 인식과 입력 조건

### 고용 서약서

새 아이콘은 기존 한국어 템플릿의 그림 부분과 픽셀이 일치한다. 고용 서약서 글자를 제외하고 76×88 / 77×88 아이콘만 사용한다. 기존 모양·색차·선택 상태 간 마진 기준은 유지했다. 영어 선택 전후와 교체 전 한국어 원본 모두에서 올바른 상태를 확인했다.

이미 테마 화면을 연 상태에서도 시작할 수 있게 했다. 테마 아이콘의 명확한 선택 전후 상태를 확인한 경우에만 재개하며, 선택 후 활성 선택 버튼을 확인하고 영입권 화면으로 넘어간다. 탐사 초기 화면의 `start` 마커를 영어로 변경한 것은 아니다.

### 영입권과 하단 공통 버튼

`recruit_card`는 기존 216×48 크기를 유지하고 중앙 `[22,7,172,34]`를 비교에서 제외한다. 직업 아이콘과 버튼 테두리를 조합하며 영문 `Recruit Hero`나 한글 영입 문구를 읽지 않는다.

하단 활성 버튼은 제공된 `employment_2.png`의 `[938,628,300,64]`에서 추출했다. 중앙 `[18,6,264,52]`는 제외하고 외곽·장식·남은 색상을 비교한다. `confirm_theme`, `recruit_active`, `enter`에 같은 기준을 사용하지만 의미는 앞선 상태 확인으로 구분한다.

- 테마 선택 버튼: 고용 서약서가 선택된 상태여야 함.
- 영웅 영입 버튼: 목표 영웅 초상화와 선택 테두리가 확인되어야 함.
- 탐사 입장 버튼: 네 직업의 영입 완료 아이콘이 확인되어야 함.

같은 테두리를 찾았다는 사실만으로 행동을 허용하지 않는다. 기존 유사도와 색차 제한은 낮추지 않았으며 제공된 비활성 버튼은 거부한다. 선택·입장 버튼의 클릭 중심은 `(1088,660)`이고, 비교에서 문구를 제외해도 전체 버튼 크기를 유지한다.

### 필터

필터 버튼은 제공된 21×18 깔때기 아이콘으로 비교한다. 기존 한국어 목록과 영어 목록에서 `(700,24,21,18)`로 검출되며 클릭 중심은 실제 필터 버튼 안이다.

열린 패널은 `[65,65,870,335]` 외곽에서 중앙 `[12,12,846,311]`을 제외해 비교하고, 속성 행 `[495,110,345,60]` 안에서 서로 다른 속성 아이콘을 3개 이상 추가 확인한다. 패널 테두리만 있는 다른 팝업이나 속성 아이콘만 남은 잘못된 화면은 인정하지 않는다.

`filter_element_label` 한글 라벨은 로딩·배포 목록에서 제외했다. 레이아웃 JSON에 남은 정의는 비교용 과거 자료이며 현재 패널 판정에는 쓰지 않는다. 기존 `filter_panel`의 한글 라벨 원본도 새 외곽 이미지로 대체했다. 속성 선택 전후 확인, 다른 속성 선택 시 중지, 패널 밖의 직업 아이콘 확인 등 기존 조건은 유지한다.

고정 패널 영역과 템플릿 크기가 같으면 검색할 위치가 하나뿐이다. 이때 큰 FFT 검색 대신 제외되지 않은 픽셀의 모양·색차를 직접 비교한다. 개발 환경의 스냅샷 10회 평균에서 닫힌 패널 확인은 약 3ms, 열린 패널 확인은 약 7ms였다. 이는 실행 중인 게임의 사이클 속도 측정이 아니다. 정상 흐름의 추가 화면 캡처나 대기는 넣지 않았다.

## 재현 검사

- 영어 테마 선택 전후와 기존 한국어 그림의 판정, 영입권 네 칸, 네 직업 완료 상태, 비활성 버튼 거부.
- 버튼의 문자 영역을 임의 픽셀로 바꿔도 위치 유지. 같은 버튼이 두 개면 모호한 대상으로 거부.
- 공통 활성 테두리가 다른 화면에 있어도 테마·영웅 선택 조건이 없으면 행동 거부.
- 테마 화면에서 재개하여 테마 선택·영입권 화면까지 진행하는 흐름 재현. 이 검사에서 실제 영입은 대체 함수로 처리한다.
- 영어 필터 패널, 문구 변경, 외곽/아이콘 누락, 필터 열기·속성 선택 흐름 재현. 속성 선택 후 화면은 기존 선택 아이콘으로 합성한 것이며 실제 영어 선택 후 캡처는 아니다.
- 영어 노드 지도와 유일한 진입 가능 전투 노드 `(190,310,83,79)` 선택.

관련 검사는 게임에 연결하거나 입력하지 않고 저장된 화면과 모의 상태 전환을 사용한다. [이미지 미리보기](exploration-image-audit.html)는 새 제외 영역도 표시하도록 갱신했다.

- 기존 영입·필터·직업 아이콘·노드·반복·UI·배포 회귀 검사 246개 통과: `logs/exploration-english-captures-regression.log`.
- 고정 패널 비교 최적화 후 최종 필터·영입·영어 캡처·배포 검사 85개 통과: `logs/exploration-english-final-checks.log`. 앞선 검사와 중복되므로 고유 검사 수로 합산하지 않는다.
- 실제 런타임의 `filter_panel`, `recruit_card`, `enter` 마스크와 생성된 미리보기 목록의 제외 영역이 일치함을 확인했다. `git diff --check` 통과.

## 남아 있는 범위

아직 제공되지 않은 화면: 탐사 초기 화면, 영웅 한 명을 선택한 영어 목록과 활성 영입 버튼, 속성 선택 후 영어 필터, 노드 상세·전투 시작·휴식·보급·상점·이벤트·정산·반복 진입.

영어 지도에서 노드를 선택하는 것과 선택 후 모든 노드를 처리하는 것은 별도 검증이다. 특히 일부 상세·결과 마커와 이벤트 제목은 아직 한글에 의존한다. 따라서 영어 UI의 탐사 탭은 계속 비활성화하며, 이번 작업을 영어 탐사 전체 지원 완료로 표시하지 않는다.
