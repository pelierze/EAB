# 이벤트 경고의 언어 독립 취소 처리

2026-10-25 15:42:41 보고는 이벤트 선택 뒤 Vitals가 최대라는 영문 경고가
나왔지만, 문구 및 기존 버튼 행으로 인식하지 못해 중지한 사례다.
이번 처리는 Vitals 같은 단어와 경고 본문의 의미를 읽지 않는다.

## 판별과 좌표

확인·취소 버튼의 기존 문자 제외 프레임을 넓은 하단 범위에서 탐색한다.
버튼 두 개가 유일하고, 같은 높이이며, 좌우 중심 간격이 맞아야 한다.
화면 전체를 가로지르는 모달 위·아래 경계선도 함께 확인한다. 일반 이벤트
선택지의 텍스트나 내부 삽화는 경고창의 근거로 사용하지 않는다.

최신 화면에서는 취소 (434,465,198,60), 확인 (649,465,198,60)을 검출한다.
기존 y=430 행이나 화면의 고정 클릭 좌표로 대체하지 않는다. 버튼·경계선이
없거나 후보가 중복되면 입력하지 않는다. 별도의 언어 OCR은 추가하지 않는다.

## 동작 정책

일반 경고의 구조를 확인한 것은 Confirm을 승인한 것이 아니다. 이벤트
경고는 취소하고, 직전에 선택한 카드 좌표를 제외 목록에 보관한 뒤 나머지
선택지로 돌아간다. 선택할 수 있는 카드가 없으면 중지한다. 클릭 직전에는
새 프레임으로 경고 상태와 취소 좌표를 다시 확인한다.

이미 의미가 확인된 영입 건너뛰기·상점 퇴장 등은 기존 전용 처리와 직전
입력에 따른 확인 권한을 유지한다. 이번 일반 경고 판별은 자동 확인 권한을
추가하지 않는다. 기존 실패 보고에는 발견한 모달과 버튼 좌표를 함께 남긴다.

실제 영문 경고 캡처와 기존 이벤트 자료로 취소 → 이전 선택지 제외 →
다른 카드 선택을 재생한다. 제목·본문·버튼 글자 제거, 버튼 행 이동,
버튼/경계 누락, 중복 후보, 클릭 전 화면 변경을 검사한다. 화면 이동과
문구 변경은 합성 검사이고 실제 게임 입력은 보내지 않는다.

검증 결과: 기존 이벤트 선택 24개와 경고·영입 건너뛰기 16개, 총 40개 검사 통과.
`compileall`과 `git diff --check`도 완료했다.
