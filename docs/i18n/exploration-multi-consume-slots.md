# 여러 전리품 소모 슬롯 지원

2026-10-27 06:45:59 오류 캡처는 빈 소모 슬롯 두 개가 (846,557),
(946,557)에 나타난다. 기존 중앙 55×55 탐색과 1/1 확인으로는 화면을
인식하거나 소모 대상을 모두 선택할 수 없었다.

`+` 탐색을 하단 트레이의 490×100 영역으로 확장했다. 흰색/중성의 작은
십자 모양 자체를 확인하며, 대각선 X·사각형·단순 선은 제외한다. 선택 후
나타나는 제거 기호도 같은 트레이에서 찾으므로, 빈 슬롯과 채워진 슬롯을
합쳐 필요한 수를 결정한다. 수평 정렬, 비중첩, 트레이 내부 위치를 확인하고
현재 84픽셀 슬롯이 들어갈 수 있는 1~5개 배치를 허용한다. 실제 캡처는
1개/2개이며 3~5개와 위치 변화는 합성 검증이다.

처음 확인한 슬롯의 개수와 위치를 유지하면서 서로 다른 인벤토리 위치를
하나씩 선택한다. 기존 금지 전리품 우선 소모 정책은 유지한다. 각 선택 후
해당 아이콘이 서로 다른 채워진 슬롯에 모두 들어갔는지 확인해야 다음
아이템을 누른다. 이미 선택된 슬롯이 있으면 해당 아이콘을 다시 눌러
해제하지 않고 남은 슬롯만 채운다. 복구 시 같은 아이콘의 인벤토리 후보가
여럿이라 어느 것이 선택됐는지 불확실하면 모두 제외하는 보수적 정책이다.
명확한 나머지 후보가 부족하면 입력하지 않고 중지한다.

확정은 빈 슬롯이 없고 선택한 아이콘 전체가 일대일로 연결될 때만 허용한다.
버튼 중앙의 문구/카운터를 마스킹하고 활성/비활성 테두리를 비교한다.
기존 1/1 문자 OCR은 제거했다. 확정 직전 슬롯과 버튼을 다시 확인하며,
입력 후에는 실제 후속 화면을 기존 이벤트 흐름으로 전달한다. 인식 재시도는
이전 클릭을 반복하지 않는다. 실패 진단에 슬롯 위치/채움 상태와 버튼 표식을
추가했으며 상시 캡처는 추가하지 않았다.

재현 검사는 실제 2슬롯 캡처, 실제 1슬롯 선택 전/후, 위치를 바꾼 1~5슬롯,
2개/3개를 차례로 선택하고 확정, 부분/전체 선택 상태에서 재개, 아이템 부족,
잘못 정렬된 슬롯과 확정 직전 비활성 전환을 포함한다. 3개 이상 선택한
화면과 위치 변화는 합성이므로 실제 게임에서의 후속 검증은 필요하다.
테스트는 실제 클릭 함수를 모의 ADB에 연결하며 게임 입력은 보내지 않는다.

사용자가 `images/raws/1.PNG`~`4.PNG`에 제공한 실제 후속 화면도 확인했다.
창 테두리(왼쪽 1픽셀, 위쪽 31픽셀)를 제외한 1280×720 게임 영역을
fixture에 저장했다. 실제 1개 선택, 2개 선택 완료, 전리품 보상 팝업,
이벤트 결과 설명으로 차례로 판별된다. 사용자가 캡처한 조각상/잎사귀
선택 순서를 재생하기 위해 해당 검사에서만 소모 후보 순서를 고정하고,
기본 금지 항목 우선 정책은 별도 회귀 검사로 유지한다. 실제 선택 상태에서
보상 팝업과 결과 설명을 닫고 기존 지도 캡처로 복귀하는 재생도 수행한다.

검증 결과: 다중 슬롯/실제 후속 장면 14개, 기존 + 모양 6개, 이벤트 모드
24개, 이벤트 흐름 17개, 이미지 패키지 6개로 총 67개 통과. 이미지 감사표
갱신, `compileall`, 변경 파일의 `git diff --check`도 완료했다.
