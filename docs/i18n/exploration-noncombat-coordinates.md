# 비전투 노드: 종류 확인 → 상징 확인 → 좌표 탐색

기존 보급·휴식 메뉴는 반투명한 버튼 전체를 참조 이미지와 비교해 배경이
바뀔 때 화면 판정이 실패할 수 있었다. 2026-10-25 08:54:45 보급 오류 보고는
상자 검출에 성공했으나 두 메뉴가 미검출인 사례다. 새 방식은 진입 정보,
현재 화면의 상징, 입력 대상의 위치를 각각 확인한다.

## 진입 정보와 재개

지도에서 선택한 노드 종류와 상세 화면 종류가 일치하고 진입 직전에도
같은 상세/버튼이 보일 때 비전투 노드 종류를 보관한다. 이전 지도 선택만으로
입력을 허용하지 않는다. 지도 복귀 시 보관한 정보를 지우며, 확인된 종류와
다른 비전투 화면이 나오면 입력을 진행하지 않는다.

중간 화면에서 재시작하면 기존 인식 결과 또는 유일한 상징 조합과 버튼
배치를 안정 프레임으로 확인해 재개한다. 일반 확인 팝업의 확인·취소 버튼이
보일 때는 배경 노드로 추정해 재개하지 않는다. 기존 인식 경로도 유지한다.

## 노드별 기준

| 노드 | 현재 화면 상징 | 좌표 탐색 및 입력 조건 |
| --- | --- | --- |
| 보급 | 뚜껑·효과를 피한 상자 하단 몸체 | 오른쪽 두 메뉴의 둥근 테두리를 찾고 아래쪽 활성 메뉴를 선택. 수령 완료 체크가 있어야 떠나기 허용 |
| 휴식 | 모닥불·깃발·영웅을 피한 텐트 고정 패치 두 곳 | 네 메뉴의 테두리/배치를 찾고 최상단 활성 메뉴만 선택. 랭크업 완료 체크가 있어야 떠나기 허용 |
| 상점 | 상인 애니메이션·대사를 피한 진열대 위/아래 고정 장식 | 글자를 제외한 나가기 프레임 탐색. 상품 구매는 기존 상품 아이콘과 상대 좌표·금액 검증 유지 |
| 이벤트 | 알려진 삽화 또는 선택지의 짝지어진 모서리 장식 | 기존 선택지 모서리로 좌표 산출. 결과 이동은 고정 좌표 대신 검출된 화살표 위치 사용 |

## 메뉴 탐색

게임 화면 1280×720에서 기존 메뉴 예상 위치 주변 ±16픽셀을 탐색한다.
330×94 둥근 테두리 모델과 실제 에지의 배치를 비교하며 글자·내부 배경·
중앙 반짝임은 모델에 포함하지 않는다. 전체 테두리와 네 모서리를 각각
확인하고, 두 개/네 개 버튼의 좌우 정렬과 세로 간격도 확인한다.
기준 좌표는 검색 범위를 정할 뿐, 검출 실패 시 클릭 좌표로 사용하지 않는다.

테두리 검출만으로 활성 상태를 가정하지 않는다. 검출된 위치에서 활성·
비활성 참조의 문자 제외 픽셀 오차를 같은 오프셋으로 비교한다. 활성 쪽이
충분히 가깝고 더 잘 맞을 때만 액션을 제공한다. 애매한 경우 클릭하지 않는다.
보급/휴식의 떠나기 좌표도 완료 체크가 없으면 입력용 컨트롤로 제공하지 않는다.

팝업·전투·보상 목록처럼 별도로 인식된 화면을 노드 배경으로 덮어쓰지 않는다.
클릭 직전에 현재 종류·상징·좌표를 다시 확인한다. 상점/보급 퇴장 직후의
일반 확인·취소 버튼은 직접 검증한 퇴장 입력 이후에만 해석하며, 다른 단계의
일반 팝업을 전역적으로 승인하지 않는다. 보급 진입 경고의 취소 버튼이 없으면
이전의 고정 좌표 대신 입력 없이 중지한다.

## 진단과 검증 범위

디버그 체크가 켜진 경우에만 `noncombat_coordinates`로 노드 종류·상징·
검출 메뉴/컨트롤 좌표 변경을 기록한다. 기존 실패 보고서에도 확인한 노드와
좌표 결과를 넣는다. 별도의 주기 캡처/이미지 수집 루프는 추가하지 않는다.
진입·버튼 입력 직전에는 화면을 다시 캡처해 확인한다.

최신 실제 영문 보급 오류 화면과 기존 영문·한글 자료를 사용한다. 메뉴 위치
이동, 상징/테두리 누락, 비활성 버튼, 완료 체크, 클릭 직전 화면 전환,
지도 복귀 시 정보 해제, 중간 화면 재개를 검사한다. 보급 수령·휴식 랭크업·
상점 퇴장·이벤트 이동을 오프라인으로 재생하며 실제 게임 입력은 보내지 않는다.
영문 상점 문구 제거본과 이동한 버튼/화살표, 일부 보상·완료 상태는 합성 검사다.
모든 비전투 이벤트 삽화 및 실제 영문 완주 검증을 의미하지 않는다.

## 상점 상세창 연결 누락 수정

2026-10-25 13:41:18 보고는 상점 내부가 아니라 진입 전 상세창에서 실패한
사례다. 상세 아이콘 등록에는 상점이 없었고, 진입 코드도 상점을 일반적인
`node_detail`로 기다렸다. 영문 Enter는 상세 아이콘을 확인한 뒤에만 공통
프레임으로 찾도록 되어 있어 버튼 테두리가 검출돼도 진입할 수 없었다.

실제 보고 화면의 오른쪽 저울 아이콘을 `shop_detail`로 등록했다. 지원 노드
목록에서 상세 상태 이름을 일관되게 생성하고, 지원 중인 모든 노드가 상세
아이콘을 갖는지도 검사한다. 다른 비전투 노드인 휴식·보급·이벤트는 이미
상세 아이콘이 등록되어 있었으며, 이들의 연결도 함께 확인한다.

최신 영문 상점 상세 화면에서 제목·설명·Enter 문구 변경, 아이콘 누락,
7종 헤더의 상호 구분과 상점 선택 → 상세 확인 → 상점 내부 확인을
재생한다. 실제 게임 입력은 보내지 않는다.

검증 기록: 최종 좌표 탐색·휴식·보급·보상 흐름 53개 테스트 통과. 별도
이벤트/복구 38개, 노드 진입·상점 구매/퇴장 관련 선택 검사도 통과했다.
기존 상점 전체 회귀에서는 구매 결과 불확실 시 중지하는 검사까지 확인했다.
`compileall`, 이미지 참조 감사표 갱신, 신규 상점 상징의 배포 포함 확인 및
`git diff --check`도 완료했다. 합성 자료와 실제 캡처 범위는 위 설명을 따른다.

상점 상세 보완 검증: 상세 아이콘·비전투 좌표 30개 테스트 통과 후, 상세 상태
매핑 변경에 대해 상점·휴식·보급·정예/보스 진입 4개 검사를 재확인했다.
신규 저울 아이콘의 배포 이미지 포함 여부도 확인했다.

## 진입 전환 상태 유지와 상세창 재개

2026-10-25 14:13:16 실제 영문 상점 화면은 진열대 상징과 나가기 좌표를
인식할 수 있었지만 실패 기록에는 확인한 노드 정보가 null이었다.
화면 분류가 지도를 한 번이라도 관측하면 정보를 지웠기 때문에, 진입
전환 중 지도 프레임이 보이는 상황에서 상점 좌표 탐색 경로가 끊길 수 있었다.

분류 관측 자체로는 노드 정보를 해제하지 않는다. 해당 단계가 지도 복귀를
허용하고 안정 프레임으로 실제 map 결과를 받아들였을 때, 또는 메인 루프에서
지도 상태가 안정적으로 확인됐을 때 해제한다. 진입 대기에서 map은 허용
결과가 아니므로 정보를 보존한다. 버튼 입력 전 현재 화면 재확인은 유지한다.

같은 날 14:11:05에 기록된 shop_detail 재개 거부도 수정했다. 종류가 명확한
지원 상세창은 지도 선택 후 진입과 동일한 확인 함수로 이어진다. 아이콘을
식별하지 못한 일반 node_detail은 종류를 추측해 진입하지 않는다.

실제 영문 상점 캡처와 기존 지도/상세/퇴장 자료를 사용해 지도 선택 재개와
상세창 직접 재개 모두에서 map → map → shop 전환을 합성 재생한다. 진입
정보 유지, 퇴장 후 지도 복귀에서 해제, 영입 단계 미재실행을 확인한다.

## 상점의 Book of the Stars 금지 판별

실제 영문 상점의 Book of the Stars는 기존 dont_select_2와 같은 금지 아이콘이지만
작은 표시 크기가 기존 배율 목록에 없어 미검출이었다. 진열대 위/아래 상징이
함께 검출된 상점에 한해 진열 영역 안에서 64픽셀 크기로 맞춘 금지 아이콘도
찾는다. 일치도 0.88과 기존 다른 화면의 탐색 배율은 바꾸지 않는다.

실제 캡처에서 dont_select_2 검출, 상품명 변경과 아이콘 제거, 검출한 금지
상품이 구매 대상으로 전달됐을 때 가격 판독 전 skip하는 조건을 검사한다.
실제 구매 기능은 기존대로 Future Investment만 대상으로 하며 임의 상품을
구매하는 기능을 추가하지 않는다. 금지 상품이 진열돼도 퇴장은 허용한다.
디버그 체크 시에는 기존 클릭 전 금지 검사 결과를 `forbidden_items`에
이름·좌표·퇴장 여부와 함께 남긴다. 이를 위한 추가 캡처나 금지 재검색은 없다.
