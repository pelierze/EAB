# 펭귄런의 문자 의존성 감사와 마스크 적용 준비

- 작업일: 2026-10-24
- 상태: 인식 경로의 마스크 지원 구현. 실제 버튼 제외 영역은 원본 화면 확보 후 확정.

구매·최대 이미지는 글자가 원본 가장자리까지 가까이 차 있다. 여유 있게 문자 영역을 제외하면 버튼을 식별할 고유한 외곽이 남지 않는다. 배경색 조각만으로 버튼을 찾도록 변경하지 않았으며, 실제 원본 PNG도 아직 교체하지 않았다. 현재 한국어 인식과 영어 모드의 기능 제한을 유지한다.

저장된 루트·로그의 화면에서 원본 템플릿을 비교했으나 펭귄 화면을 확보하지 못했고, 연결된 ADB 장치도 없었다. 이 결과는 게임 화면 전체의 탐지 성능 검증을 의미하지 않는다.

## 구현한 마스크 경로

`PenguinBot`의 템플릿 로딩을 비밀상점과 같은 `ImageMatcher`에 연결했다. 템플릿 옆 `template_masks.json`이나 PNG 알파 채널로 문자 제외 영역을 지정할 수 있다. 아직 확정하지 않은 마스크 JSON은 추가하지 않았다.

- 전체 탐색, 단일 탐색, 팝업 ROI 탐색과 후보 재채점에 동일한 마스크를 사용한다.
- 마스크가 없는 기존 PNG는 기존 컬러 매칭·배율 처리·좌표를 유지한다.
- 마스크가 있는 이미지를 확대·축소할 때 색상과 알파를 같은 필터로 처리하고, 완전히 불투명한 픽셀만 비교한다. 제외한 글자가 보간을 통해 비교 영역으로 섞이는 것을 방지한다.
- 마스크는 템플릿 전체 크기를 보존하므로 클릭 중심과 ROI 결과의 좌표 변환을 유지한다.
- `images/penguin/template_masks.json`이 추가되면 배포 이미지 수집 과정에 자동으로 포함한다. 검토용 하위 폴더의 이미지는 배포하지 않는다.
- 스크린샷 횟수와 대기 시간은 추가하지 않았다. 실제 마스크 적용 후 인식 시간은 실화면으로 다시 측정해야 한다.

## 필요한 화면과 다음 작업

1. 1280×720 원본 펭귄 목록 화면: 알 아이콘과 해당 상품의 구매 버튼 전체를 포함한다.
2. 같은 해상도의 구매 수량 팝업: 최대 버튼, 최종 구매 버튼, 수량 영역을 포함한다. 가능하면 최대 선택 전후를 모두 확보한다.
3. 각 버튼의 테두리·여백을 포함한 새 원본을 자르고, 중앙 문구를 여유 있게 제외한다. 목록 구매와 팝업 구매는 현재 글자 이미지를 공유하지만, 전체 버튼의 모양·크기가 다르면 템플릿을 분리한다.
4. 알 아이콘 아래 같은 상품 버튼, 팝업 안 최대·최종 구매 ROI를 기준으로 다른 버튼과의 오인식을 검사한다. 마스크가 넓어진 만큼 같은 외형의 버튼을 구분하는 위치·화면 상태 조건도 확인한다.
5. 한국어·영어 동일 상태 화면에서 숫자·화살표 인식, 최대 선택, 최종 구매, 완료 팝업 닫기, 중지·실패 흐름을 검증한 뒤 영어 모드의 펭귄 기능을 연다.

## 자동 검증

관련 111개 검사가 통과했다. 펭귄의 기존 사이클 동작, 공통 마스크 경로, UI·업데이트·창 크기 오류 번역, 기존 비밀상점 마스크, 배포 자산·패키지를 포함한다.

새 마스크 검사는 합성된 테두리와 변경된 중앙 픽셀을 사용해 제외 영역 독립성, ROI 좌표, 0.95~1.15 배율, 빈 화면·어두운 버튼 거부를 확인했다. 이는 마스크 처리 코드의 검증이며 실제 펭귄 버튼의 정확도나 영어 게임 지원 완료를 입증하지 않는다.
