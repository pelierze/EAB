# 눈 이벤트의 설명과 다음 선택지 연결

2026-10-26 16:52:57 보고의 중지는 설명 화면을 인식한 다음 `_tap`에
`(640, 490)` 두 값을 넘겨 발생한 `ValueError`였다. 클릭 함수는
`(x, y, width, height)`를 받으므로 실제 ADB 입력 전에 실패했다.
본문 입력을 `(640, 490, 0, 0)`으로 수정한다.

사용자가 같은 보고 폴더에 제공한 `epicseven 2026-10-26 20-27-51-91.png`는
그 다음 세 선택지 화면이다. 설명은 진입 이력이 있을 때 `event_intro`,
다음 화면은 `unknown_event`로 연결된다. 선택지 등장 시 설명 진입 상태를
해제하고 기존 허용 후보 선택 및 실제 후속 화면 처리로 넘긴다.

추가 캡처에서는 오른쪽 위 선택지 장식 세 개는 검출되지만, 왼쪽 아래
장식은 배경 날개와 겹쳐 가운데 하나만 검출됐다. 기존 왼쪽 장식 격자
폴백과 대칭으로 오른쪽 장식 격자도 지원한다. 오른쪽 장식 2~3개가 같은
높이와 기존 380픽셀 간격으로 배열되고, 실제 왼쪽 장식이 하나 이상
짝을 이뤄야 한다. 이 조건에서만 가려진 왼쪽 장식의 카드 위치를 보완한다.
왼쪽 기준이 전혀 없거나 오른쪽 간격/정렬이 다르면 카드를 추정하지 않는다.
문자·문구·OCR은 사용하지 않는다.

기존 설명 처리는 한 입력 뒤 실제 화면 변화를 기다린다. 본문 표시만
바뀌고 설명 화면이 유지되면 이벤트 흐름으로 다시 관측해 다음 설명
입력을 처리하며, 한 번 클릭하면 반드시 선택지가 나온다고 가정하지 않는다.
변화가 없는 화면에는 자동으로 같은 클릭을 반복하지 않는다.

재현 fixture에는 보고의 설명 캡처와 사용자가 추가한 선택지 캡처를 그대로
저장한다. 실제 `_tap` 함수를 모의 ADB에 연결해 두 값/네 값 형식 오류까지
검사한다. 실제 설명 → 제공된 선택지와, 합성 미완성 지문 → 전체 지문 →
제공된 선택지 두 경로를 확인한다. 이후 선택 동작 검증에는 기존 지도
캡처를 후속 화면으로 재생한다. 선택지 각각을 고른 실제 결과 캡처는
제공되지 않았으므로 세 분기의 실제 결과까지 검증한 것은 아니다.
실제 게임 입력은 보내지 않는다.
