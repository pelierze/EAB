# 보급 메뉴: 보물상자와 두 번째 메뉴 인식

- 날짜: 2026-10-24
- 브랜치: `codex/i18n-dimensional-exploration`
- 실제 오류: 22:04:55, 영어 보급 내부 화면에서 노드 진입 확인 시간 초과. 상자와 메뉴가 보이지만 한글 전리품 문구와 떠나기 문구를 인식하지 못했다.

## 인식과 동작

보물상자 하단 몸체, 오른쪽 메뉴 두 개, 글자를 제외한 나가기 버튼을 함께 확인해 보급 화면을 구분한다. 두 번째 메뉴가 활성 상태이고 완료 체크가 없을 때 가운데를 누른다. 첫 번째 영웅 영입 메뉴는 선택하지 않는다.

|---|---|---|
| 닫힌 상자 하단 | `[590,515,120,35]` | `supply_menu_local_live.png` |
| 열린 상자 하단 | `[590,515,120,35]` | `supply_done_live.png` |
| 첫 메뉴 | `[905,258,330,94]` | 위 두 원본의 활성/비활성 프레임 |

상자는 `[575,505,155,60]` 안에서 비교하며, 뚜껑과 위쪽 효과·영웅 영역을 피한다. 닫힘/열림의 몸체를 둘 다 참고한다. 메뉴는 내부 `[20,20,290,58]`의 글자를 제외한다. 첫 메뉴는 활성 상태가 달라도 위치와 모양만 확인하며 두 번째 메뉴의 활성 판정과 분리한다. 두 번째 활성/완료 프레임과 실제 완료 체크는 별도로 확인한다.

기존 전리품 선택·금지 아이템 제외·보상 팝업 처리는 유지한다. 전리품 화면으로 넘어간 뒤 보급 메뉴 좌표를 재사용하지 않는 조건도 유지한다. 나가기는 보급 화면과 완료 체크가 함께 확인될 때만 허용한다. 글자가 사라지거나 버튼이 비활성화되었다는 이유만으로 획득 완료를 판단하지 않는다.

나가기 버튼 하나만으로 휴식 화면이라고 분류하던 남은 경로는 제거했다. 휴식은 고정 배경과 메뉴 4개, 보급은 상자와 메뉴 2개의 조합으로 구분한다. 보급의 완료·나가기 조건이 강화되어, 보상 팝업 뒤 복귀 화면을 사용한 기존 재생 검사도 실제 완료 화면으로 교체했다.

## 자료와 검증 범위

실제 영어 오류 화면은 `tests/fixtures/exploration/english_supply_menu_20261024.npz`의 `screen`에 보존했다. 원본은 `logs/report/20261024_220455_435636_세션_1_c8e7491d/screen.png`이다.

검사는 실제 영어 화면의 두 번째 메뉴·나가기 검출, 글자·뚜껑/효과·영웅 변경, 상자나 메뉴 프레임 누락 거부, 열린 상자·완료 체크, 완료되지 않은 상태의 나가기 거부를 포함한다. 화면 재생에서는 영어 보급 → 기존 전리품 화면 → 글자를 지운 완료 화면 → 지도 순서로 진행하고 보급 입력이 두 번째 메뉴와 나가기 각 한 번인지 확인한다. 전리품 선택 처리 자체는 이 재생 검사에서 모의 처리하며 게임에는 입력하지 않는다.

영어 전리품 카드·획득 버튼·보상 팝업·완료 후 확인창의 전체 흐름은 아직 실제 화면으로 확인하지 않았다. 영어 완료는 기존 한글 완료 원본의 문구를 제거한 검사이며 실제 영어 완료 캡처와 구분한다.

실패 보고서에 닫힌/열린 상자 몸체, 첫 메뉴, 두 번째 완료 프레임의 검출 결과를 추가했다. 상세 점수 기록은 기존대로 디버그 모드에서만 생성한다. 추가 캡처나 고정 대기는 넣지 않았다. 비교 영역은 [이미지 감사표](exploration-image-audit.html)에서 확인할 수 있다.
