# 차원 탐사 영어 지원: 1차 작업

- 날짜: 2026-10-24
- 브랜치: `codex/i18n-dimensional-exploration`
- 상태: UI·설정 값 분리와 필터 아이콘 인식 구현. 영어 게임 전체 실행 지원 전.

## 구현한 내용

- 랭크업 우선순위의 표시 문구와 내부 값을 분리했다. 콤보박스 선택 인덱스를 `1, 2, 3, 4, null`에 대응시켜 사용하며, 실행 순서 판정에서 `1순위` 같은 한글을 비교하지 않는다. `null`은 제외를 뜻한다.
- 기존 `exploration-presets.json`의 `1순위`~`4순위`, `제외` 값을 읽을 수 있다. 이후 저장할 때는 숫자/null을 쓴다. 영웅은 기존대로 ID로 저장하며 언어 변경 시 선택 인덱스를 유지한다. 파일 경로·세션별 저장·원자적 교체 방식을 유지한다.
- 기존 v1.6.0 이하 앱은 숫자형 우선순위를 읽지 못한다. 이 개발 브랜치로 설정을 저장한 뒤 구버전으로 돌아가면 우선순위를 다시 선택해야 한다. 영웅 ID와 코스트 대체 옵션의 형식은 같다.
- 영입·이벤트·상점·완주 횟수 설정의 제목, 직업·영웅·속성 이름, 우선순위, 고코스트 경고, 시작·중지·설정 오류 안내를 번역 경로에 연결했다. 언어 변경 시 영웅·우선순위·진행 중 통계를 유지한다. 일반 로그와 동적으로 만들어지는 단계·종료 사유 전체의 번역은 이번 범위가 아니다.
- 1순위 중복 시 기존 1순위 영웅을 비어 있는 우선순위로 옮기는 동작은 숫자로 처리한다. 전부 제외했을 때 선택 영웅 순서로 돌아가는 기존 동작은 유지한다.
- 필터 버튼의 비교 영역을 한글 문구 대신 깔때기 아이콘 `[10,12,28,29]`로 제한했다. 원본 PNG는 보존하며, 감지 결과의 중심은 실제 필터 버튼 내부에 있다. 직업 아이콘·필터 패널 상태 확인 등 기존 입력 전 조건도 유지한다.

## 이미지·인식 조사

- [실제 비교 영역 미리보기](exploration-image-audit.html)
- [소스·crop·region·임계값·배포 포함 여부 목록](exploration-image-audit.json)
- 재생성: `python tools/audit_exploration_images.py`

총 265개 비교 영역을 수집했다: 영입 마커 57개, 노드·이벤트 마커 198개, 대체 초상화 1개, 테마 전후 2개, 금지 아이템 3개, 직업 아이콘 4개. 미리보기는 저장소 내 원본 이미지를 참조하므로 저장소 폴더 구조를 유지한 상태로 연다.

목록의 임계값·색차 값은 JSON에 명시된 설정이다. `null`이면 비교를 생략한다는 뜻이 아니라 해당 observer의 기본값·분기를 확인해야 한다는 뜻이다. 영입의 기본 유사도는 0.90, 일반 색차 한도는 0.09이며 직업 아이콘 등은 별도 분기를 사용한다.

**이 목록은 크롭 목록이다. 265개 모두의 한글 의존성 판정이나 영어 실화면 검증을 끝냈다는 의미가 아니다.** JSON의 review 상태는 의도적으로 미확정이며, 아래 표는 우선 살펴본 실제 비교 영역과 호출 경로에 한정한다. 로딩되는 이미지와 실제 입력을 결정하는 이미지를 구분해야 한다.

| 대상 | 실제 확인한 내용 | 처리·다음 작업 |
|---|---|---|
| `recruitment/filter` | 한글 필터 문구와 깔때기 그림 | 그림만 비교하도록 구현. 저장된 영웅 목록과 문자 영역 변경·아이콘 누락을 검사 |
| `knight`, 직업 header·완료 아이콘 | 방패 등 직업 도형 | 공통 후보. `hero_completed()`는 이미 완료 직업 아이콘과 빈 영입 슬롯을 조합해 판정 |
| 영웅별 `completed_name` | 로딩 목록에 이름 마커가 남아 있음 | 현재 `hero_completed()`의 입력 근거로 쓰이지 않음. 로딩 사실만으로 이름 판독이 필수라고 판단하지 않음 |
| `recruitment/start`, `unlock`, `confirm_theme`, `completed` | 탐사 시작·신규 추정 보급 해금·선택하기·영입 완료의 글자 위주 | 넓은 원본을 다시 확보하거나 다른 화면 앵커로 대체 필요 |
| `recruit_card`, `recruit_active` | 글자와 버튼의 테두리·배경 | 중앙 마스크 후보. 활성 상태·다른 버튼·클릭 후 상태를 함께 비교해야 함 |
| `filter_panel`, `filter_element_label` | 세트·속성의 한글 라벨 | 현재 필터 패널 판정에 사용됨. 영문 패널의 도형·배치 확인 후 공통 앵커로 대체 필요 |
| 테마 `select_supply_1/2` | 고유 그림, 고용 서약서 문구, 선택 전후 배경 | 문구 제외 후보. 현재 도형·절대 색차·상태 간 마진을 쓰므로 글자만 지우고 기존 판정을 그대로 신뢰할 수 없음 |
| 노드 `enter`, `enter_node`, `battle_start`, `continue`, `leave`, `rank_title`, `rank_button`, `story_confirm`, `exploration_entry` | 대부분 글자만 잘라 놓은 영역 | 단순히 비우면 식별 근거가 부족함. 테두리 포함 원본이나 단계별 복수 앵커 필요 |
| `map_footer`, `rest_done` | 장식·체크 도형 | 공통 후보. 실제 영어 화면의 위치·상태 비교 필요 |
| `hero_departure_title`, `expedition_summary`, `recruit_reward_title`, `shop_purchase_dialog`, `shop_future_investment_title`, `shop_purchase_button` | 화면·상품을 구별하는 한글 제목 또는 버튼 문구 | 영문 대응 화면의 도형·상품 아이콘과 상태 확인으로 대체 검토 |
| `shop_investment_confirm_item` | 미래 투자 상품 아이콘 | 제목 대신 쓸 공통 후보이나, 다른 상품·구매 전후·재화 변화 조건까지 함께 검사해야 함 |

`NodeObserver.is_rank_result()`는 화살표와 `RANK UP` OCR을 함께 확인한다. 이 부분은 이미 영문 문자열을 사용한다. 숫자·랭크·잔액 OCR도 별도 경로가 있으므로 템플릿의 한글만 제외했다고 전체 언어 의존성이 사라지는 것은 아니다. 등록 이벤트 전체의 선택·결과·복구 경로는 후속 조사 대상이다.

## 다음에 필요한 영어 게임 화면

우선 아래 1280×720 원본을 `images/raws/`에 모아 단계별로 확인한다.

1. 탐사 시작 화면, 테마 미선택·선택 상태.
2. 영웅 영입 카드 화면, 직업별 영웅 목록, 필터 닫힘·열림·속성 선택 상태.
3. 영웅 선택 전·후, 영입 버튼 활성 상태, 네 직업 영입 완료 상태.
4. 노드 지도, 전투·휴식·보급·상점의 상세 화면과 입장 버튼.
5. 랭크업, 영입 보상, 미래 투자 구매 전·후, 이탈 영웅 선택, 최종 정산과 반복 진입 화면.

문자 제외 후 식별력이 충분한 마커부터 적용하고, 같은 도형의 다른 버튼과 화면에서 오인식하지 않는지 확인한다. 실제 영어 탐사 흐름을 검증하기 전에는 영어 UI의 탐사 탭 제한을 해제하지 않는다.

## 검증 기록

- 직접 영향받는 UI·프리셋·영입·필터·직업 아이콘·펭귄·배포 회귀 검사 188개가 통과했다. 로그: `logs/exploration-i18n-focused-tests.log`.
- 이후 추가한 실행기 전달 검사를 포함해 실제 Tk 위젯 기반 UI 검사 8개가 통과했다. 로그: `logs/exploration-i18n-ui-tests.log`. 앞선 회귀 검사와 중복되는 검사가 있으므로 두 숫자를 고유 검사 수로 합산하지 않는다.
- 기존 한글 프리셋을 영어 UI에서 복원, 숫자/null 저장과 언어 전환 후 선택 유지, 1순위 중복 해소, 영어 UI에서 내부 영웅 ID 순서 전달을 확인했다.
- 저장된 13개 영웅 목록에서 필터 아이콘이 검출되고, 모집 완료 화면에서는 검출되지 않는다. 버튼 문구를 임의 픽셀로 바꿔도 인식하지만 아이콘을 없애면 거부한다. 실제 영어 필터 화면의 검증은 아니다.
- 모든 테스트의 언어 저장 경로를 임시 폴더로 격리했다. 프리셋 관련 검사는 각 테스트에서 별도의 임시 저장 경로를 사용한다. 실제 게임에 입력하거나 재화를 소모하지 않았다.
- 전체 노드·등록 이벤트 회귀 검사와 실제 영어 탐사 반복 실행은 완료하지 않았다. 이미지 인벤토리의 소스 경로 265개는 존재를 확인했다.
