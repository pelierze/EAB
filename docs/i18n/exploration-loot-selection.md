# 전리품 선택 목록 영문 인식

2026-10-25 08:35:43 오류 보고에서는 전투 결과에서 전리품 버튼 클릭까지
성공했지만, 목록 하단 확정 버튼이 한글 문구 조각에 의존해 `loot` 상태를
판정하지 못했다. 카드 3개의 재설정 아이콘과 배치는 이미 인식되고 있었다.

활성/비활성 확정 버튼을 334×70 테두리 전체 참조로 교체하고 중앙 문구는
마스크로 제외한다. 외곽 밝기 차이를 포함해 두 상태를 구분하도록 같은
위치에서 양쪽 참조와 비교하고, 활성 참조 점수가 0.02 이상 높을 때만
활성으로 인정한다. 기존 활성 참조 임계값 0.88과 비활성 0.90은 유지한다.
테두리가 공통인 다른 화면과 혼동하지 않도록 활성 확정 버튼은
재설정 아이콘 3개와 선택 테두리 1개가 있을 때만 반환한다.

기존 `_loot`의 금지 아이템 제외, 카드 배치 확인, 선택 대상 재확인,
확정 직전 재검사, 수령 후 화면 전환 확인은 유지한다. 선택됐어도 버튼이
비활성이거나 버튼만 활성이고 카드가 선택되지 않으면 확정하지 않는다.

실제 영문 미선택 화면을 회귀 자료로 보존했다. 영문 선택 완료 캡처는 아직
없으므로 선택 테두리와 활성 버튼은 기존 한글 자료를 영문 화면에 합성해
검사한다. 합성 선택 화면에서 문구를 지워 언어와 무관한 비교도 확인한다.
금지된 첫 카드를 제외하고 두 번째 카드를 선택 → 선택 상태 확인 → 수령 →
승리 화면 복귀를 재생한다. 게임에는 입력하지 않는다.

검증: 전리품 선택·기존 보상 흐름·보급 메뉴의 27개 테스트와 추가한 애매한
활성 상태 검사 1개, 총 28개 통과. 실패 진단에는 선택 테두리 검출도 추가했다.
