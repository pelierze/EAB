# v1.5.18 배포 검증 기록

- 병행 채팅의 데스티나 스킨 템플릿 및 대체 영웅 지원 작업 완료를 확인한 뒤 완료 아이콘 검색 범위를 수정했다. 영입 재클릭과 앱 시작 시 실제 앱 버전 기록 변경도 함께 배포한다.
- 이슈 19의 추가 보고서는 실제 앱 버전 1.5.17이며, 오공 완료 아이콘이 원본보다 왼쪽으로 13픽셀 이동했다. 네 직업의 검색 영역을 해당 카드 안에서 76×52로 넓히고 기존 템플릿·상관계수·색상 오차·영입권 부재 조건을 유지했다.
- 실제 오류 캡처, 전 직업 위치 변동 및 잘못된 아이콘/슬롯 부정 검증, 영입 재시도, 기본·스킨 데스티나 및 대체 영입, 필터·선택 테두리·완료 아이콘·복구·배포 자산·업데이트 관련 검사 152개가 통과했다. 별도로 추가한 실제 이슈 화면에서 오공 완료 확인 시 재클릭하지 않는 통합 검사 1개도 통과했다. 로그: `release/v1.5.18-tests.log`.
- 앱 시작 버전 기록은 실제 `bot.log` 파일을 만드는 수동 검사로 확인했다. 원격 스크립트 버전과 별도로 `구동 앱 버전`을 출력한다.
- `build_release.ps1 -Version v1.5.18`로 앱과 자동 업데이트 실행 파일을 빌드하고 배포 폴더 검증을 통과했다. 앱 실행 파일의 파일·제품 버전은 모두 1.5.18이다. ZIP과 자동 업데이트용 SHA256 파일을 생성했다. 빌드 로그: `release/v1.5.18-build.log`. `git diff --check` 통과.
- 실제 게임 연속 실행, 스킨 데스티나의 게임 내 영입 완료까지의 실행, 배포본 간 자동 업데이트는 직접 수행하지 않았다.
