# 휴식 랭크업 결과창 복귀 보완

2026-10-11 16:08:50 오류 보고서에서 그림자 로제의 랭크업 결과창이 남아 있는데 휴식 완료 확인을 기다리다 중지했다. 로그에는 닫기 입력 없이 `rank_result → event_loot_popup`으로 화면이 바뀌었다고 기록되어 있다.

랭크업 결과와 전리품 결과는 하단 X를 공유한다. 실제 보고서 캡처에서 랭크업 글자 OCR을 실패하도록 재현하면 이전 분류기는 전리품 결과창으로 판단했다. 저장된 마지막 캡처만으로 당시 순간적인 인식 실패가 OCR 때문인지 화살표 인식 때문인지는 확정할 수 없다.

랭크업 화살표가 보이지만 글자를 확인하지 못하면 미확인 상태로 기다리도록 변경했다. 글자와 화살표를 모두 확인한 경우에만 기존 랭크업 닫기를 허용한다. 휴식 랭크업의 반환 상태도 이어서 처리하여 남은 획득 결과창을 닫고, 휴식 화면 또는 지도 복귀를 확인한 뒤 진행한다. 지도로 이미 복귀했다면 휴식 떠나기 버튼을 다시 누르지 않는다.

검증에는 해당 보고서 캡처를 사용한다. 글자 OCR 실패 시 공유 X가 있어도 전리품으로 오인하지 않는지, 인식이 회복되면 닫기를 한 번 전송하는지, 일반 전리품 처리가 유지되는지, 추가 결과창 처리 이후 휴식 완료를 확인하는지와 지도 복귀 시 이전 버튼을 누르지 않는지를 검사한다. 실제 게임에서의 재실행 확인은 별도로 필요하다.
