## 원인과 처리

2026-10-11 14:37:24 보고서는 4회 완주 후 5회차의 이벤트 선택 결과 확인에서 종료됐다. 선택지 입력은 완료됐지만 후속 `이탈 영웅 선택` 화면이 미지원이었다.

- 해당 제목과 `탐사대 이탈` 버튼을 함께 인식해 별도의 이벤트 화면으로 분류한다.
- 영웅 이름·랭크·직업을 읽지 않고 공통 카드 모서리로 표시된 목록을 확인한다. 이미 선택된 카드의 금색 테두리도 목록에 포함한다.
- 안정된 목록을 다시 확인한 뒤 후보 중 한 명을 무작위로 선택한다.
- 선택한 카드의 금색 테두리, 동일한 영웅 초상화, 활성화된 이탈 버튼을 함께 확인하고 입력 직전에도 재검사한다.
- 이탈 버튼 입력 직후 확인·취소 버튼이 있는 확인창이 나오면 확인 버튼을 검증하고 누른다. 이전 입력을 모르는 상태에서 임의 확인창을 확정하지 않는다.
- 이탈 후 대화·보상·지도·전투 및 패배는 기존 진행 절차로 넘긴다. 이탈이 전투 승패를 미리 결정하지는 않는다.
- 로그에 무작위 선택, 선택 상태 검증 및 이탈 완료를 기록하고 보고서의 departed_heroes에 완료 횟수를 남긴다.

검증 결과: 영웅 이탈 테스트 12개 통과. 기존 이벤트 흐름·선택지 재시도·설명창·완주/패배 반복·배포 이미지 검증 55개도 통과하여 합계 67개 통과했다.
