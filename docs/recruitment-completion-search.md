실제 보고서 캡처에서 라스·오공 완료와 나머지 미영입을 구분하는지, 모든 직업의 아이콘 위치 변화, 잘못된 클래스·아이콘 누락·다른 슬롯·영입권/목록 화면의 부정 검증을 수행한다. 보고서 원본은 테스트에만 사용하고 배포에는 넣지 않는다. 영입 재클릭은 클릭 누락을 위한 별도 보완이며, 이미 완료된 이번 화면에서는 재클릭하지 않는다.
