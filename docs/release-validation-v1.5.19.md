# v1.5.19 배포 검증 기록

- 비밀상점 일반·상단 복귀 드래그의 최근 2회 전후 PNG를 기존 캡처에서 재사용하여 오류 보고서의 `scrolls` 폴더에 저장한다. 캡처 시각·용도·드래그 좌표·입력 성공 여부와 누락 사유를 `report.json`에 기록한다. 실행 시작 시 이력을 초기화하고, 정상 실행 중에는 별도 진단 이미지 파일을 쓰지 않는다.
- 드래그당 별도 ADB 캡처 호출이 없음을 호출 횟수로 확인했다. 최대 2회 이력 제한, 파일 덮어쓰기 이후 원본 유지, 캡처 실패 시 낡은 파일 미사용, 입력 실패·후속 캡처 누락, 선택적 진단 이미지 저장 실패 시 기본 보고서 보존을 검증했다. 실제 처리 시간의 성능 측정은 수행하지 않았다.
- 스토리 스킵 이슈 21 수정 커밋 db41f6b도 포함한다. 사용자 캡처 재생 및 스킵 직후에만 일반 버튼을 확인창으로 처리하는 범위를 검증했다.
- 상점·드래그 진단·오류 보고서·ADB 입력·스토리·이벤트 순회·영웅 보상 건너뛰기·결과창 닫기·배포 자산·업데이트 관련 121개 검사가 통과했다. 로그: `release/v1.5.19-tests.log`.
- 기존 스크롤 단위 검사는 진단 상태를 초기화하도록 보완했다. 이미 보관 처리되어 GUI에 존재하지 않는 이벤트 실행 함수에 대한 오래된 보고서 검사 항목을 제거했으며, 지원 중인 상점·펭귄·탐사의 오류 보고서 검사는 유지한다.
- `build_release.ps1 -Version v1.5.19`로 앱과 자동 업데이트 실행 파일을 빌드하고 배포 폴더 검증을 통과했다. 앱 실행 파일의 파일·제품 버전은 모두 1.5.19이다. ZIP과 자동 업데이트용 SHA256 파일을 생성했다. 빌드 로그: `release/v1.5.19-build.log`. `git diff --check` 통과.
- MuMu 사용자 환경의 화면 전환 원인은 확정하지 않았다. 실제 게임 실행과 배포본 간 자동 업데이트는 직접 수행하지 않았다.
