# v1.6.0 배포 검증 기록

- 기준: `main`의 PR #24 머지 커밋 `4a66bfd`. 배포 커밋에서 앱 버전, Windows 버전 정보, 빌드 기본 버전을 1.6.0으로 맞췄다.
- 관련 자동 검사 207개 통과. 언어 선택·저장·업데이트 복원, 영어 펭귄 탭, 펭귄 실화면 앵커 재현, 비밀상점 수량 변화·스크롤·디버그, 업데이트·롤백, 기존 바로가기 전환, 배포 자산·패키지 검사를 포함한다. 로그: `release/v1.6.0-tests.log`.
- 사용자 언어 설정을 변경하지 않도록 검사 중 설정 저장 경로를 임시 폴더로 격리했다.
- `build_release.ps1 -Version v1.6.0 -SkipDependencyInstall`로 Windows 앱·업데이트 프로그램·기존 바로가기 호환 실행기를 빌드했다. 로그: `release/v1.6.0-build.log`.
- `dist/EAB/EAB.exe`의 파일·제품 버전이 모두 1.6.0이다. 실행 파일에 포함된 Python 모듈에서도 앱 버전, 언어 선택 메뉴, 스티그마·+1 기반 펭귄 인식 코드가 포함된 것을 확인했다.
- 패키지 생성 단계에서 build/eab 프로필 검증을 통과했다. `EAB-v1.6.0.zip`은 204,590,503 bytes, 1,243 entries이며 ZIP CRC와 SHA256 일치를 확인했다. EAB.exe, EAB-Updater.exe, 기존 실행명 호환 실행기 및 펭귄 런타임 템플릿·마스크 정의를 포함하며 raw 캡처·검토용 마스크·테스트는 포함하지 않는다.
- v1.5.15/v1.5.19 원본 업데이트 코드가 EAB 패키지·공식 EAB 주소·새 실행 파일을 지원함을 확인했다. 배포본 사이의 실제 자동 업데이트를 수행한 것은 아니다.
- 실제 게임 구매·반복 실행, 완료 팝업, 한국어·영어 같은 상태의 실기 비교는 수행하지 않았다. 펭귄 완료 흐름은 기존 화살표를 합성한 화면으로 검사했다. 새 배포 실행 파일을 직접 실행해 UAC 또는 사용자의 게임 환경을 변경하지 않았다.
- 사용자 릴리즈 노트는 `docs/releases/v1.6.0.md`를 그대로 게시하며 내부 검증 결과와 체크섬 안내를 넣지 않는다. ZIP과 체크섬 파일 업로드 후 서버의 파일 크기·SHA256 digest를 비교하고 정식 최신 릴리즈로 공개한다.
