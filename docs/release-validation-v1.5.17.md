# v1.5.17 배포 검증 기록

- 이슈 18의 실제 v1.5.16 캡처에서 필터 메뉴와 불 속성 선택은 인식되지만 목록의 기사 아이콘은 보이지 않는 상황을 재현했다. 필터가 목록을 가리므로 대상 영웅 부재로 판단하지 않는다.
- 클래스 확인을 필터 열기 전으로 한정하고, 열린 메뉴의 속성 확인에서 목록 아이콘 의존성을 제거했다. 필터/속성 상태를 입력 전후로 확인하며 최대 3회 재시도한다. 열려 있는 필터나 이미 선택된 속성에는 중복 입력하지 않는다.
- 실제 캡처·기존 영입 흐름·재시도·선택 테두리·완료 아이콘·인식 복구·업데이트·릴리즈 조회·배포 자산 관련 129개 테스트가 통과했다. 로그: `release/v1.5.17-tests.log`.
- 과거 등록 이벤트 정책을 전제로 `_unknown_event`를 차단했던 복구 테스트를 현재 무작위 선택 정책에 맞췄다. 선택지 준비 확인이 실패하면 무작위 선택 및 입력을 수행하지 않는 검증은 유지한다. 이벤트 실행 코드는 변경하지 않았다.
- `build_release.ps1 -Version v1.5.17`로 앱과 자동 업데이트 실행 파일을 빌드하고 배포 폴더 검증을 통과했다. 앱 실행 파일의 파일·제품 버전은 모두 1.5.17이다. ZIP과 자동 업데이트용 SHA256 파일을 생성했다. 빌드 로그: `release/v1.5.17-build.log`.
- `git diff --check` 통과. 실제 게임 연속 실행과 배포본 간 자동 업데이트는 직접 수행하지 않았다.
