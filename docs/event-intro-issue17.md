# 17번 이슈: 이벤트 진입 설명창

## 원인

17번 이슈의 v1.5.14 보고서는 2026-10-11 10:52:26 이벤트 진입 이후 노드 내부 진입 확인에서 약 90초간 입력 없이 대기하다 종료됐다. 첨부 화면은 선택지와 하단 진행 화살표가 없는, 중앙의 작은 설명창이다. 기존 이벤트 결과창의 화살표 인식 조건에는 해당하지 않는다. v1.5.15에서도 첨부 화면의 상태는 None으로 재현된다.

## 변경과 범위

- 이벤트 노드 상세 화면과 진입 버튼을 확인하고 실제 진입한 직후에만 설명창 보조 인식을 활성화한다.
- 기존 화면 판별과 선택지·결과 화살표 확인을 먼저 수행한다. 기존 후속 화면이 확인되면 보조 인식은 종료한다.
- 중앙 설명창 상단의 장식과 그 아래 여러 줄의 연보라 본문 영역을 함께 확인한다. 지문 내용과 배경 그림은 비교하지 않는다.
- 확인된 설명창의 본문을 한 번 누른 뒤 본문의 유의미한 변화 또는 기존 후속 화면을 기다린다. 본문 바깥 배경 애니메이션은 진행으로 취급하지 않는다. 변화가 없으면 재입력하지 않고 기존 타임아웃으로 종료한다.
- 여러 설명 페이지는 기존 이벤트 진행 루프에서 한 페이지씩 처리하며 기존 시간·횟수 제한을 유지한다.
- 선택지 무작위 처리, 금지 선택지 제외, 보상 수령·랭크업·전투 처리 및 기존 하단 화살표 범위는 변경하지 않는다.
