# Epic7 Assist Bot (EAB) v1.7.3

## 변경 사항

- 일부 보안 제품의 탐지와 관련해 배포 파일 및 실행 방식을 정리했습니다. 백신별 판정은 다를 수 있으므로 이 변경만으로 모든 탐지가 해제되는 것은 아닙니다.
- 기존 바로가기 전환과 업데이트 후 임시 파일 정리 방식을 개선했습니다. 기존 바로가기와 자동 업데이트는 계속 사용할 수 있습니다.

## 업데이트 및 실행

v1.5.15 이상에서는 **업데이트 후 재시작**으로 설치할 수 있습니다. 업데이트 후 봇은 자동으로 재개하지 않습니다.

수동 설치 시 아래 Assets에서 `EAB-v1.7.3.zip`을 내려받으세요. 실행 중인 앱을 종료하고 새 폴더에 전체 압축을 푼 뒤 `EAB.exe`를 실행하세요. v1.5.14 이하는 수동 설치가 필요합니다.

## English

- Cleaned up the release files and launch behavior in response to antivirus detection reports. This does not guarantee that every security product will stop flagging the app.
- Improved legacy shortcut migration and cleanup after updates. Existing shortcuts and automatic updates remain supported.

Versions 1.5.15 and later can use **Update & Restart**; versions 1.5.14 and earlier require a manual installation. Running bots do not resume automatically after updating.

Download `EAB-v1.7.3.zip`, extract the entire folder, and run `EAB.exe`.
