# Epic7 Assist Bot (EAB) v1.5.18

- 영웅을 영입했는데도 완료 상태를 인식하지 못해 다음 직업으로 넘어가지 못하는 문제를 개선했습니다. 카드 안에서 클래스 아이콘 위치가 조금 달라져도 인식합니다.
- 영입 클릭이 반영되지 않으면 같은 영웅의 선택 상태와 활성 영입 버튼을 다시 확인하여 최대 두 번 추가 클릭합니다.
- 스킨을 착용한 데스티나도 영입 대상으로 인식합니다. 기본 모습과 스킨 모습 모두 지원하며 대체 영웅으로 선택될 때도 적용됩니다.
- 앱 시작 로그에 실제 구동 앱 버전을 표시합니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

직접 설치하거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.18.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요. 같은 Windows 사용자의 마지막 탐사 프리셋은 유지됩니다.
