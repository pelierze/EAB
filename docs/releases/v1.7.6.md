# Epic7 Assist Bot (EAB) v1.7.6

## 변경 사항

- 탐사 중 스토리가 끝나거나 스킵 확인창에서 레벨업·보상 화면으로 넘어갔을 때, 확인 버튼을 계속 기다리다 종료되는 문제를 개선했습니다.
- 스토리의 문구와 버튼 언어가 달라도 화면의 아이콘과 버튼 테두리를 기준으로 스킵을 처리하도록 개선했습니다.
- 스킵·확인 입력이 누락되면 현재 화면을 다시 확인하고 제한된 횟수만 재시도합니다.
- 오류 보고서에 최근 탐사 화면과 주요 전환 화면이 함께 저장됩니다. 문제 신고 시 `logs/report`의 해당 보고서 폴더 전체를 ZIP으로 첨부해 주세요. 첨부 전 화면에 개인정보가 포함되어 있는지 확인해 주세요.
- 스킵·퇴장 입력 이력이 없는 확인창에서 탐사를 시작하거나 다시 시작하면 자동 확인을 보류할 수 있습니다. 해당 창을 직접 처리한 뒤 탐사를 시작해 주세요.

## 업데이트 및 실행

v1.5.15 이상에서는 **업데이트 후 재시작**으로 설치할 수 있습니다. 업데이트 후 봇은 자동으로 재개하지 않습니다.

수동 설치 시 아래 Assets에서 `EAB-v1.7.6.zip`을 내려받으세요. 실행 중인 앱을 종료하고 새 폴더에 전체 압축을 푼 뒤 `EAB.exe`를 실행하세요. v1.5.14 이하는 수동 설치가 필요합니다.

## English

- Exploration now handles stories that end or move to level-up/reward screens while a skip confirmation is pending.
- Story skipping uses icons and button borders rather than localized captions.
- Missed skip/confirmation inputs are retried a limited number of times after verifying the current screen.
- Error reports now include recent exploration screenshots and key transitions. Attach the entire report folder under `logs/report` as a ZIP when reporting a problem, and check screenshots for personal information before sharing.
- A confirmation dialog without a verified skip or exit input may require manual handling before starting or resuming exploration.

Versions 1.5.15 and later can use **Update & Restart**; versions 1.5.14 and earlier require a manual installation. Running bots do not resume automatically after updating.

Download `EAB-v1.7.6.zip`, extract the entire folder, and run `EAB.exe`.
