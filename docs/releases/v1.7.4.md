# Epic7 Assist Bot (EAB) v1.7.4

## 변경 사항

- 한 화면에서 여러 상품을 연속 구매할 때, 앞선 상품의 구매 효과가 다음 상품의 구입 버튼을 잠시 가리는 경우 버튼을 다시 확인하도록 개선했습니다.
- 재확인 중에는 추가 구매 입력을 하지 않으며, 화면 효과가 사라진 뒤 다음 상품 구매를 계속합니다.

## 업데이트 및 실행

v1.5.15 이상에서는 **업데이트 후 재시작**으로 설치할 수 있습니다. 업데이트 후 봇은 자동으로 재개하지 않습니다.

수동 설치 시 아래 Assets에서 `EAB-v1.7.4.zip`을 내려받으세요. 실행 중인 앱을 종료하고 새 폴더에 전체 압축을 푼 뒤 `EAB.exe`를 실행하세요. v1.5.14 이하는 수동 설치가 필요합니다.

## English

- When buying multiple products from the same shop screen, the bot now rechecks the next purchase button if the preceding purchase effect temporarily obscures it.
- Rechecks do not send additional purchase input; the bot continues after the screen effect clears.

Versions 1.5.15 and later can use **Update & Restart**; versions 1.5.14 and earlier require a manual installation. Running bots do not resume automatically after updating.

Download `EAB-v1.7.4.zip`, extract the entire folder, and run `EAB.exe`.
