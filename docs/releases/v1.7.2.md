# Epic7 Assist Bot (EAB) v1.7.2

## 변경 사항

- **비밀상점에서 성약의 책갈피 등을 구매한 뒤 구매 알림 때문에 중단되는 문제를 개선했습니다.** 구매 알림이 상품 이미지를 가리면 잠시 기다렸다가 완료 상태를 다시 확인합니다. 이 과정에서 구매 버튼을 다시 누르지 않으며, 계속 확인되지 않으면 중지합니다.

## 사용 안내

기존 설정 그대로 사용할 수 있습니다. 구매 완료 확인 횟수를 1회로 설정해도 상품 이미지가 일시적으로 가려진 경우에는 잠시 기다린 뒤 다시 확인합니다.

## 업데이트 및 실행

v1.5.15 이상에서는 **업데이트 후 재시작**으로 설치할 수 있습니다. 업데이트 후 봇은 자동으로 재개하지 않습니다.

수동 설치 시 아래 Assets에서 `EAB-v1.7.2.zip`을 내려받으세요. 실행 중인 앱을 종료하고 새 폴더에 전체 압축을 푼 뒤 `EAB.exe`를 실행하세요. v1.5.14 이하는 수동 설치가 필요합니다.

## English

- **Improved purchase verification when a Secret Shop purchase notification temporarily covers the product image.** The bot waits briefly and checks again without pressing the purchase button again. It stops if the result still cannot be confirmed.

Your existing settings can be kept. Temporary product image obstruction is rechecked even when the purchase verification count is set to one.

Versions 1.5.15 and later can use **Update & Restart**; versions 1.5.14 and earlier require a manual installation. Running bots do not resume automatically after updating.

Download `EAB-v1.7.2.zip`, extract the entire folder, and run `EAB.exe`.
