# Epic7 Assist Bot (EAB) v1.5.17

- 탐사 영웅 영입 중 속성을 선택했는데도 선택 완료 확인에서 멈추는 문제를 수정했습니다. 필터 창이 영웅 목록을 가리는 경우에도 진행합니다.
- 필터 열기나 속성 선택이 반영되지 않으면 현재 화면을 다시 확인하고 최대 3회 시도합니다. 이미 열린 필터나 선택된 속성은 다시 누르지 않습니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

직접 설치하거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.17.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요. 같은 Windows 사용자의 마지막 탐사 프리셋은 유지됩니다.
