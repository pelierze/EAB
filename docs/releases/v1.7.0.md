# Epic7 Assist Bot (EAB) v1.7.0

## 변경 사항

- **차원 탐사에서 영어 게임 화면과 영어 UI를 지원합니다.** 앱 상단 Language 메뉴에서 한국어·영어를 선택할 수 있으며, 게임 언어는 따로 바꾸지 않아도 됩니다.
- 탐사의 영웅 영입, 휴식·보급·상점, 이벤트, 전투 보상과 종료 화면 처리를 개선했습니다. 전리품과 영웅 영입 보상이 함께 나오는 경우와 전리품을 여러 개 소모하는 이벤트도 처리합니다.
- **탐사 일시정지·재개** 버튼을 추가했습니다. 일시정지가 확인된 뒤 다른 게임 작업을 하고, 진행 중이던 탐사 화면으로 돌아와 재개하세요. 게임 자체가 정지되지는 않으며 앱 종료 후에는 재개할 세션이 유지되지 않습니다.
- 한국어·영어 오류 신고 양식과 오류 보고서 첨부 안내를 제공합니다.

## 사용 안내

게임에서 원하는 탐사 난이도를 선택하고 시작 화면이나 진행 중인 노드 지도를 열어 둔 뒤 실행하세요. 이벤트 선택지는 내용을 읽어 최적 선택을 하는 방식이 아니므로 불리한 결과가 나올 수 있습니다. 인식하지 못하는 화면에서 중지되면 로그에 표시되는 보고서 폴더 전체를 ZIP으로 첨부해 주세요. 일부 실행 로그는 영어 UI에서도 한국어로 표시됩니다.

## 업데이트 및 실행

v1.5.15 이상에서는 **업데이트 후 재시작**으로 설치할 수 있습니다. 업데이트 후 봇은 자동으로 재개하지 않습니다.

수동 설치 시 아래 Assets에서 `EAB-v1.7.0.zip`을 내려받으세요. 실행 중인 앱을 종료하고 새 폴더에 전체 압축을 푼 뒤 `EAB.exe`를 실행하세요. v1.5.14 이하는 수동 설치가 필요합니다.

## English

- **Dimensional Exploration now supports English game screens and the English app interface.** Choose Korean or English from the Language menu without changing the game's language.
- Improved exploration recruitment, rest, supply, shops, events, battle rewards, and ending screens. Combined loot and hero rewards and events requiring multiple loot sacrifices are handled.
- Added **Pause / Resume** for exploration. Wait for the app to confirm it has paused before doing another in-game task. Return to the ongoing exploration screen before resuming. This does not pause the game, and the session is not preserved after closing the app.
- Bug reports can be submitted in Korean or English, with instructions for attaching the error report folder.

Select the exploration difficulty in the game and leave the starting screen or an ongoing run's node map open before starting. Event choices are selected without reading their descriptions and can have unfavorable outcomes. If the bot stops on an unrecognized screen, attach the entire report folder shown in the logs as a ZIP. Some runtime logs remain in Korean.

Download `EAB-v1.7.0.zip`, extract the entire folder, and run `EAB.exe`. Versions 1.5.15 and later can use **Update & Restart**; versions 1.5.14 and earlier require a manual installation. Running bots do not resume automatically after updating.
