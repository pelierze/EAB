# Epic7 Assist Bot (EAB) v1.7.1

## 변경 사항

- **비밀상점 자동화에서 이미 구매한 상품이 다음 화면에 남았을 때 봇이 중단되는 문제를 해결했습니다.** 첫 페이지에서 구매한 아이템이 스크롤 후에도 화면에 걸쳐 있을 때, 이미 구매 완료된 비활성화 버튼을 정상 인식하고 건너뛰어 다음 갱신을 계속 진행합니다.

## 사용 안내

비밀상점 화면을 열어둔 상태에서 원하는 리프레시 횟수를 설정하고 시작하세요.

## 업데이트 및 실행

v1.5.15 이상에서는 **업데이트 후 재시작**으로 설치할 수 있습니다. 업데이트 후 봇은 자동으로 재개하지 않습니다.

수동 설치 시 아래 Assets에서 `EAB-v1.7.1.zip`을 내려받으세요. 실행 중인 앱을 종료하고 새 폴더에 전체 압축을 푼 뒤 `EAB.exe`를 실행하세요. v1.5.14 이하는 수동 설치가 필요합니다.

## English

- **Fixed an issue where Secret Shop automation halted when a purchased item remained visible after scrolling.** When an item bought on the first page still appears on the scrolled screen, the bot now correctly recognizes the disabled purchase button, skips the item, and continues with the next refresh.

Run the bot with the Secret Shop open and your desired refresh count configured.

Versions 1.5.15 and later can use **Update & Restart**; versions 1.5.14 and earlier require a manual installation. Running bots do not resume automatically after updating.

Download `EAB-v1.7.1.zip`, extract the entire folder, and run `EAB.exe`.
