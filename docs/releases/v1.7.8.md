# Epic7 Assist Bot (EAB) v1.7.8

## 변경 사항

- 비밀상점 자동화나 자연 갱신 구매를 시작할 때, 감지된 화면 해상도가 권장 크기인 **1280×720**과 다르면 현재 해상도와 오작동 가능성을 안내합니다.
- 안내가 뜨면 **계속하기**를 선택해야 시작합니다. **취소**를 누르거나 창을 닫으면 화면 크기를 조정한 뒤 다시 시작할 수 있습니다.

## 업데이트 및 실행

v1.5.15 이상에서는 **업데이트 후 재시작**으로 설치할 수 있습니다. 업데이트 후 봇은 자동으로 재개하지 않습니다.

수동 설치 시 아래 Assets에서 `EAB-v1.7.8.zip`을 내려받으세요. 실행 중인 앱을 종료하고 새 폴더에 압축을 모두 푼 뒤 `EAB.exe`를 실행하세요. v1.5.14 이하는 수동 설치가 필요합니다.

## English

- Secret Shop automation and natural refresh purchases now display the detected resolution and warn about possible issues when it differs from the recommended **1280×720**.
- Choose **Continue** to start. Choose **Cancel** or close the dialog to adjust the resolution before trying again.

Versions 1.5.15 and later can use **Update & Restart**. Earlier versions require a manual installation. Running bots do not resume automatically after updating.

For manual installation, close the app, download `EAB-v1.7.8.zip`, extract it to a new folder, and run `EAB.exe`.
