# Epic7 Assist Bot (EAB) v1.5.19

- 비밀상점 오류 보고서에 최근 드래그 2회의 전후 화면을 함께 저장합니다. 일반 스크롤과 상단 복귀 스크롤을 구분해, 동작 중 다른 화면으로 전환되는 문제를 확인하기 쉽게 했습니다. 문제 신고 시 `scrolls`가 포함된 보고서 폴더 전체를 ZIP으로 첨부해 주세요. 확보하지 못한 화면은 보고서에 누락 사유를 기록합니다.
- 탐사 보스전 후 스토리 스킵 확인창에서 멈추는 문제를 개선했습니다. 확인창의 문구나 배경이 달라도 스킵을 이어가도록 했습니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

직접 설치하거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.19.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요. 같은 Windows 사용자의 마지막 탐사 프리셋은 유지됩니다.
