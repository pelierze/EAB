# Epic7 Assist Bot (EAB) v1.5.16

- 탐사 이벤트의 소개 화면에서 선택지로 넘어가지 못하고 멈추는 문제를 수정했습니다.
- 이벤트 선택지가 바뀌면 잠시 기다린 뒤 다시 확인하여 진행합니다.
- 영웅 이탈 화면에서는 표시된 영웅 중 한 명을 무작위로 선택하고 탐사대 이탈을 확정합니다. 파티원이 줄어들어 이후 전투에서 패배할 수 있습니다.
- 영웅 이탈 후 지도를 인식하지 못해 다음 노드에 진입하지 못하는 문제를 수정했습니다.
- 휴식 랭크업 결과창에서 멈추는 문제를 개선했습니다. 남은 결과창을 닫고 휴식 화면이나 지도로 복귀한 뒤 진행합니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

직접 설치하거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.16.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요. 같은 Windows 사용자의 마지막 탐사 프리셋은 유지됩니다.
