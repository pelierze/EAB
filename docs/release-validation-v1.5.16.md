# v1.5.16 배포 검증 기록

- 이벤트 소개 화면 진입, 선택지 변경 시 대기 후 재확인, 무작위 영웅 이탈 처리, 파티원 수와 무관한 지도 인식, 휴식 랭크업 결과창 복귀 개선을 포함한다.
- 최근 오류 보고서의 실제 캡처와 모의 화면 전환으로 검증했다. 랭크업·결과창 닫기·노드 진행·배포 자산 87개, 일시적인 OCR 실패 후 닫기 1개, 이벤트 소개·영웅 이탈·선택지 재확인 28개 검사가 통과했다.
- 배포 전 업데이트·릴리즈 조회·업데이트 안내·배포 자산 검사 37개가 추가로 통과했다. 로그: `release/v1.5.16-tests.log`.
- 사용자용 릴리즈 노트는 사용자가 체감하는 변화와 영웅 이탈에 따른 파티 손실 및 업데이트 방법을 안내한다.
- `build_release.ps1 -Version v1.5.16`로 앱과 자동 업데이트 실행 파일을 빌드하고 배포 폴더 검증을 통과했다. 앱 실행 파일의 파일·제품 버전은 모두 1.5.16이다. ZIP과 자동 업데이트용 SHA256 파일을 생성했다. 빌드 로그: `release/v1.5.16-build.log`.
- `git diff --check` 통과.
- 실제 게임 연속 실행, 실제 영웅 이탈 선택·확인 화면, 배포본 간 자동 업데이트는 직접 수행하지 않았다. 관련 제한은 각 변경의 개발 문서에도 기록했다.
