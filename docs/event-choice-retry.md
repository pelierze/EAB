# 이벤트 선택지 변경 시 대기 및 재선택

## 배경

2026-10-11 12:03:45의 v1.5.15 오류 보고서는 2회 완주 후 3회차 이벤트에서 `이벤트 입력 직전 선택지 변경`으로 종료됐다. 하단 게임 이용 시간 안내가 선택지와 겹쳐 있었다. 현재 방식은 선택지 모서리와 화면 서명을 엄격하게 비교하므로 일시적인 안내도 입력 직전 변화로 판단할 수 있다.

## 변경

선택지 확인부터 입력 직전 검증까지 최대 3번 시도한다. 검토 중 화면이 바뀌거나 선택한 후보가 입력 직전에 비활성/금지 상태로 확인되면 입력하지 않는다. 1초 기다린 뒤 기존 안정화 대기(기본 2개 연속 프레임 일치)를 처음부터 수행하고, 현재 화면의 금지·비활성·이미 거절한 선택지를 제외한 후보를 새로 고른다. 이전 좌표는 재사용하지 않는다.

재확인 도중 보상·결과·지도 등 기존 후속 화면이 나타나면 해당 처리로 넘어간다. 3번 모두 입력 직전 검증에 실패하면 추가 입력 없이 종료하며, 재시도 안내와 최종 중지 이유를 로그에 남긴다. 대기 중 사용자 종료도 즉시 반영한다. 안정화 대기 자체는 기존 인식 타임아웃을 따른다.

선택지 모서리 템플릿, 이미지 인식 범위, 화면 서명, 밝기·금지 이미지 판정은 변경하지 않았다. 앞서 완료한 17번 설명창 처리는 별도로 유지한다.

## 검증

새 테스트는 입력 직전 페이지 변경, 검토 중 변경, 새로 금지/비활성화된 후보, 거절한 후보 유지, 재확인 중 후속 화면으로 전환, 사용자 종료, 변화 없는 기존 단일 입력을 검증한다. 기존의 계속 변경되는 실제 이미지 테스트는 3회 재확인 후 입력 없이 중지하는 기대 동작으로 갱신했다. 실제 게임의 일시 안내 출현/소멸을 연속 캡처해 실행하는 검증은 아직 하지 않았다.

검증 결과: 재시도, 이벤트 모드, 등록 이벤트, 이벤트 흐름, 17번 설명창 및 배포 이미지 테스트 합계 68개 통과(270.073초). 등록된 42개 이벤트 캡처도 기존 후보 선택 동작을 유지했다.
