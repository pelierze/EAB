# 영입 클릭 누락 복구

이슈 19의 로그에서는 라스 영입 확인 후 오공의 금색 선택 테두리와 활성 영입 버튼을 확인하고 클릭했지만, 오공 영입 완료 확인이 시간 초과됐다. 정령사 단계에는 진입하지 않았다. 첨부 로그에 오류 화면이 없어 실제 클릭 누락인지 완료 아이콘 인식 실패인지는 확정하지 않는다.

영입 버튼의 최초 입력 이후 완료 확인 단계만 보완한다. 3초가 지난 뒤에도 완료가 확인되지 않고, 기존에 선택한 영웅의 초상 및 금색 테두리와 활성 영입 버튼이 안정적으로 인식되는 경우에만 추가 입력을 허용한다. 입력 직전 새 캡처에서 완료 여부와 같은 버튼을 다시 확인한다. 완료 화면·필터 메뉴·미확인 전환 화면·선택 해제·다른 영웅·비활성 버튼에는 재입력하지 않는다.

추가 입력은 최대 2회이며 입력 사이에 최소 3초를 둔다. 이후에도 완료가 확인되지 않으면 기존 인식 시간 초과 절차에 따라 중지한다. 필터 설정과 영웅 선택 단계는 반복하지 않으며, 초기 비용 초과 및 대체 영입 판단은 유지한다. 기사 단독 및 파티 영입에 같은 완료 확인 함수를 사용한다.

클릭 누락 복구, 완료 후 중복 입력 방지, 로딩·다른 영웅·금색 테두리 누락·필터 열림·비활성 버튼에서 입력 금지, 최대 입력 횟수와 간격, 입력 직전 화면 전환 및 사용자 중단, 기존 기사/파티 영입과 선택 테두리/스토리 확인 처리 관련 65개 검사가 통과했다. 로그는 `release/recruit-retry-tests.log`에 보관한다. 실제 게임에서의 클릭 누락 복구는 아직 직접 확인하지 않았다.
